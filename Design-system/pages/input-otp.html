Input OTP

복사·붙여넣기를 지원하는 접근 가능한 일회용 비밀번호(OTP) 입력 컴포넌트입니다.

Pattern

pattern prop으로 OTP 입력에 허용할 문자 패턴을 지정합니다.

Separator

InputOTPSeparator로 입력 그룹 사이에 구분자를 추가합니다.

Disabled

disabled prop으로 입력을 비활성화합니다.

Controlled

value와 onChange prop으로 입력 값을 제어합니다.

Enter your one-time password.

Invalid

슬롯에 aria-invalid를 지정하면 오류 상태를 표시합니다.

Four Digits

PIN 코드에 자주 쓰이는 4자리 패턴입니다. pattern={REGEXP_ONLY_DIGITS}를 사용합니다.

Alphanumeric

REGEXP_ONLY_DIGITS_AND_CHARS로 숫자와 문자를 모두 허용합니다.

Form

Card·Field·Button과 함께 사용하는 OTP 인증 폼 예시입니다.

API Reference

InputOTP

data-slot="input-otp" 루트 요소입니다.

속성 타입 기본값
data-max-length number —
data-default-value string —
data-value string —
data-pattern "digits" | "alphanumeric" —
disabled boolean false
required boolean false

InputOTPSlot

data-slot="input-otp-slot" 요소는 각 OTP 자릿수를 표시합니다.

속성 타입 기본값
data-index number —
data-active "true" —
aria-invalid boolean —

InputOTPGroup

data-slot="input-otp-group" 요소는 슬롯을 그룹으로 묶습니다.

속성 타입 기본값
data-size "form" —

InputOTPSeparator

data-slot="input-otp-separator" 요소는 role="separator"와 함께 사용합니다.

속성 타입 기본값
data-spacing "wide" —
role "separator" "separator"
aria-orientation "vertical" —
