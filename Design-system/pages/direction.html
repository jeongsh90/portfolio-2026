Direction

앱의 텍스트 방향(ltr 또는 rtl)을 설정하는 프로바이더입니다. data-slot="direction-provider"로 콘텐츠를 감싸고 dir 또는 data-direction으로 방향을 지정합니다. 자식 컴포넌트는 논리 속성(margin-inline-start, padding-inline 등)을 사용하면 LTR·RTL 모두에서 올바르게 배치됩니다.

API Reference

DirectionProvider

data-slot="direction-provider" 래퍼에 텍스트 방향을 지정합니다.

속성 타입 기본값 설명
data-slot "direction-provider" — DirectionProvider 래퍼를 식별합니다.
dir "ltr" | "rtl" "ltr" HTML 방향 속성. 자식 요소에 상속됩니다.
data-direction "ltr" | "rtl" "ltr" dir과 동기화되는 데이터 속성. CSS·JS 상태 참조용.
