API Reference

Pagination

data-slot="pagination" 루트 nav 요소입니다.

속성 타입 기본값 설명
aria-label string "pagination" 탐색 영역 라벨.
role "navigation" "navigation" 접근성 역할.

PaginationContent

data-slot="pagination-content" 페이지 링크 목록(ul)입니다.

속성 타입 기본값 설명
추가 속성 없음

PaginationItem

data-slot="pagination-item" 목록 항목(li)입니다.

속성 타입 기본값 설명
추가 속성 없음

PaginationLink

페이지 번호 링크입니다. Button ghost / outline 스타일을 사용합니다.

속성 타입 기본값 설명
data-active "true" | "false" "false" 현재 페이지 강조(outline).
data-size "icon" "icon" 아이콘 크기 버튼(정사각형).
aria-current "page" — 활성 페이지일 때 page.

PaginationPrevious

data-slot="pagination-previous" 이전 페이지 링크입니다.

속성 타입 기본값 설명
aria-label string "Go to previous page" 스크린 리더용 라벨.

PaginationNext

data-slot="pagination-next" 다음 페이지 링크입니다.

속성 타입 기본값 설명
aria-label string "Go to next page" 스크린 리더용 라벨.

PaginationEllipsis

data-slot="pagination-ellipsis" 생략 표시(…)입니다.

속성 타입 기본값 설명
aria-hidden "true" "true" 장식용 아이콘 숨김.
