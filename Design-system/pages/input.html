Input

폼과 사용자 데이터 입력에 사용하는 텍스트 입력 컴포넌트입니다. 기본 스타일과 접근성 속성이 포함되어 있습니다.

API 키는 암호화되어 안전하게 저장됩니다.

Basic

가장 단순한 입력 필드입니다.

Field

Field, FieldLabel, FieldDescription으로 라벨과 설명이 있는 입력 필드를 만듭니다.

계정에 사용할 고유한 사용자 이름을 입력하세요.

Field Group

FieldGroup으로 여러 Field 블록을 묶어 폼을 구성합니다.

이 주소로 업데이트를 보내드립니다.

Disabled

disabled 속성으로 입력을 비활성화합니다. 비활성 스타일을 적용하려면 Field에 data-disabled="true"를 추가합니다.

이 필드는 현재 비활성화되어 있습니다.

Invalid

aria-invalid 속성으로 입력을 유효하지 않음으로 표시합니다. Field에 data-invalid="true"를 추가해 스타일을 적용합니다.

이 필드에 유효성 검사 오류가 있습니다.

File

type="file" 속성으로 파일 입력을 만듭니다.

업로드할 사진을 선택하세요.

Inline

Field에 data-orientation="horizontal"을 사용해 인라인 입력을 만듭니다. Button과 함께 검색 입력을 구성할 수 있습니다.

Grid

그리드 레이아웃으로 여러 입력 필드를 나란히 배치합니다.

Required

required 속성으로 필수 입력을 표시합니다.

이 필드를 반드시 입력해야 합니다.

Badge

라벨에 Badge를 넣어 추천 필드 등을 강조합니다.

Input Group

입력 안에 아이콘, 텍스트, 버튼을 추가하려면 InputGroup 컴포넌트를 사용합니다.

https://

Button Group

입력에 버튼을 추가하려면 ButtonGroup 컴포넌트를 사용합니다.

Form

여러 입력, Select, 버튼으로 구성된 전체 폼 예시입니다.

이메일은 절대 공유하지 않습니다.
