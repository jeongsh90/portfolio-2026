API Reference

DrawerContent

data-slot="drawer-content" 요소는 role="dialog"과 함께 사용합니다.

속성 타입 기본값
data-direction "top" | "right" | "bottom" | "left" "bottom"
role "dialog" "dialog"
aria-modal "true" "true"
aria-labelledby string —
aria-describedby string —

DrawerClose

data-drawer-close 속성이 있는 요소를 클릭하면 drawer가 닫힙니다.

속성 타입 기본값
data-drawer-close boolean —
data-slot="drawer-close" "drawer-close" —
