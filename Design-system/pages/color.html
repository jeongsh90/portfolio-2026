API Reference

Color tokens

컴포넌트 CSS에서는 --color-* 별칭 또는 시맨틱 변수를 사용합니다.

별칭 시맨틱 변수 설명
--color-background --background 페이지 배경
--color-foreground --foreground 기본 텍스트
--color-primary --primary 주요 액션·강조
--color-muted --muted 보조 배경
--color-border --border 테두리
--color-ring --ring 포커스 링
