Time Picker

Date Picker와 동일하게 Popover 트리거 안에 선택값을 모아 보여줍니다. 다만 옵션은 Select 드롭다운이 아니라, MUI Time Picker처럼 오전/오후·시·분이 각각 독립적으로 스크롤되는 항상 펼쳐진 목록(data-slot="time-picker-column") 형태입니다. 여백·폰트 크기는 디자인 시스템 토큰을 그대로 사용합니다.

API Reference

Combobox

입력과 팝업 목록을 결합한 루트 컴포넌트입니다.

속성 타입 기본값 설명
data-multiple "true" | "false" "false" 다중 선택 모드. ComboboxChips와 함께 사용합니다.
data-auto-highlight "true" | "false" "false" 필터 시 첫 번째 항목을 자동으로 하이라이트합니다.
disabled boolean false ComboboxInput에 적용해 비활성화합니다.
aria-invalid "true" | "false" — 유효하지 않음 상태. 입력에 파괴적 테두리·링을 표시합니다.

ComboboxItem

팝업 목록의 개별 옵션입니다.

속성 타입 기본값
data-value string —
data-disabled "true" | "false" "false"

ComboboxGroup

관련 옵션을 그룹으로 묶습니다. ComboboxLabel과 함께 사용합니다.

속성 타입 기본값
data-value string —

Time Picker

data-slot="time-picker" 래퍼 안에 data-mode="select" Combobox를 세그먼트별로 배치합니다. 별도 루트 컴포넌트 없이 Combobox 조합으로 구성합니다.

속성 위치 설명
data-slot="time-picker" 루트 Popover를 감싸는 래퍼. Date Picker와 동일한 구조입니다
data-slot="time-picker-value" 트리거 버튼 내부 선택된 "오후 08:54" 형식의 값을 표시하는 텍스트. data-empty로 빈 상태 스타일을 적용합니다
data-slot="time-picker-panel" PopoverContent 내부 오전/오후·시·분 컬럼을 가로로 배열하는 컨테이너. 컬럼 사이에 구분선이 있습니다
data-slot="time-picker-column" Panel 내부 옵션 버튼 목록. overflow-y: auto로 독립적으로 스크롤됩니다. data-segment로 컬럼을 구분합니다
data-slot="time-picker-option" Column 내부 개별 옵션 버튼. data-selected="true"인 항목은 강조 배지로 표시됩니다
data-segment="period" Column 루트 오전/오후 컬럼. 다른 컬럼보다 너비가 약간 넓습니다
