API Reference

Collapsible

접기/펼치기 루트 요소입니다.

속성 타입 기본값 설명
data-state "open" | "closed" "closed" 현재 열림/닫힘 상태 (JS가 설정)
data-default-open boolean — 마운트 시 열린 상태로 시작
data-open "true" — data-default-open과 동일한 초기 열림 효과
data-disabled boolean — 트리거 비활성화
data-variant "muted" — 배경 강조 스타일
data-size "sm" | "md" | "lg" — 최대 너비 프리셋

CollapsibleTrigger

속성 타입 기본값 설명
data-variant "link" | "ghost" — 트리거 버튼 스타일
aria-expanded "true" | "false" "false" 접근성: 패널 열림 여부

CollapsibleContent

슬롯 설명
collapsible-content 애니메이션 래퍼. data-state로 표시/숨김
collapsible-content-inner 실제 콘텐츠. 높이 측정에 사용
