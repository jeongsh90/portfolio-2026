API Reference

ContextMenuItem

data-slot="context-menu-item" 속성입니다.

속성 타입 설명
data-variant "default" | "destructive" 항목 스타일
data-inset boolean 왼쪽 여백 확대
disabled boolean 항목 비활성화

ContextMenuCheckboxItem

속성 설명
aria-checked 체크 상태 ("true" | "false")
data-checked 초기 체크 상태

ContextMenuRadioItem

속성 설명
data-value 라디오 항목 값
aria-checked 선택 상태
