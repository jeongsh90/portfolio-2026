Sides

API Reference

HoverCard

data-slot="hover-card" 루트에 열림·닫힘 지연을 지정합니다.

속성 타입 기본값
data-open-delay number 700
data-close-delay number 300

HoverCardContent

data-slot="hover-card-content" 카드 본문입니다.

속성 타입 기본값
data-side "top" | "right" | "bottom" | "left" "bottom"
data-align "start" | "center" | "end" "center"
data-side-offset number 4
