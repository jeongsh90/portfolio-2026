Spinner

로딩·처리 중 상태를 표시하는 스피너 컴포넌트입니다.

Size

data-size로 스피너 크기를 변경합니다. 기본값은 default(16px)입니다.

Button

버튼에 스피너를 넣어 로딩 상태를 표시합니다. 레이블 앞은 data-icon="inline-start", 뒤는 data-icon="inline-end"를 사용합니다.

Badge

뱃지에 스피너를 넣어 진행 중 상태를 표시합니다.

API Reference

Spinner

로딩 상태를 나타내는 회전 아이콘입니다. role="status"와 aria-label을 함께 사용합니다.

속성 타입 기본값 설명
data-size "default" | "sm" | "md" | "lg" "default" 스피너 크기. sm 12px, default 16px, md 24px, lg 32px.
data-icon "inline-start" | "inline-end" — Button·Badge 내부에서 아이콘 간격 위치.
role "status" — 접근성용 로딩 상태 역할.
aria-label string "Loading" 스크린 리더용 로딩 설명.
className string — 추가 스타일 클래스.
