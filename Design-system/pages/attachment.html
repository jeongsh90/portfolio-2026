API Reference

Attachment

첨부파일 루트 컴포넌트입니다. 미디어·콘텐츠·액션·트리거를 감쌉니다.

속성 타입 기본값 설명
data-state "idle" | "uploading" | "processing" | "error" | "done" "done" 업로드 생명주기 상태.
data-size "default" | "sm" | "xs" "default" 컴포넌트 크기.
data-orientation "horizontal" | "vertical" "horizontal" 미디어와 콘텐츠의 배치 방향.
class string — 추가 스타일 클래스.

AttachmentMedia

파일 아이콘 또는 이미지 썸네일을 표시하는 미디어 영역입니다.

속성 타입 기본값 설명
data-variant "icon" | "image" "icon" 아이콘 또는 이미지 표시 모드.
class string — 추가 스타일 클래스.

AttachmentContent

제목과 설명을 담는 콘텐츠 영역입니다.

속성 타입 기본값 설명
class string — 추가 스타일 클래스.

AttachmentTitle

파일 이름 또는 제목 텍스트입니다. uploading·processing 상태에서 shimmer 애니메이션이 적용됩니다.

속성 타입 기본값 설명
class string — 추가 스타일 클래스.

AttachmentDescription

파일 크기, 진행률 등 보조 정보를 표시합니다. error 상태에서 destructive 색상이 적용됩니다.

속성 타입 기본값 설명
class string — 추가 스타일 클래스.

AttachmentActions

삭제·재시도 등의 액션 버튼 컨테이너입니다. z-index: 20으로 트리거 위에 위치합니다.

속성 타입 기본값 설명
class string — 추가 스타일 클래스.

AttachmentAction

icon-xs 크기의 ghost 스타일 액션 버튼입니다.

속성 타입 기본값 설명
data-size "icon-xs" "icon-xs" 버튼 크기 (항상 icon-xs).
aria-label string — 접근성 레이블 (필수).
class string — 추가 스타일 클래스.

AttachmentTrigger

카드 전체를 클릭 가능하게 만드는 절대 위치 트리거입니다. z-index: 10으로 미디어·콘텐츠 위에 위치하며 액션(z-20)은 그 위에 렌더됩니다.

속성 타입 기본값 설명
aria-label string — 접근성 레이블 (필수).
class string — 추가 스타일 클래스.

AttachmentGroup

여러 첨부파일을 가로 스크롤 영역에 나열하는 컨테이너입니다. scroll-snap과 양쪽 끝 fade 효과가 포함됩니다.

속성 타입 기본값 설명
class string — 추가 스타일 클래스.
