Shadow

UI 깊이(elevation)는 box-shadow와 z-index를 레벨별로 함께 지정합니다. var(--shadow-*) 토큰만 사용하고, px·rgba 하드코딩은 하지 않습니다.

Surface Card · Table
ring z 0
Overlay Select · Popover
--shadow-md z 50
Modal Dialog · Sheet
--shadow-lg z 300

아래 → 위로 갈수록 shadow가 커지고 z-index가 높아집니다.

Elevation

[Universal Design System](https://www.figma.com/design/Ha8xNOsgvHrkpv5UKiNMYu/Universal-Design-System-25.05.12-%7C-Preview?node-id=8621-83895) elevation 가이드에 따라, 화면 구성 요소는 아래에서 위로 쌓입니다. 각 단계마다 shadow·z-index를 함께 지정합니다.

Surface z 0–1
Card · Table

ring 1px — elevation shadow 없음

Button · Input

--shadow-xs — 인터랙션 표면

Header · Sidebar

--shadow-sm — 고정 패널

--shadow-md — 플로팅 메뉴

Sheet z 300
Sheet · Drawer

--shadow-lg + overlay blur

Modal z 300–301
Dialog · Alert Dialog

--shadow-lg 또는 ring — 최상위 콘텐츠

Toast z 9999
Sonner

--shadow-lg — 항상 최전면

레이어 z-index Shadow 예시
Surface 0–1 ring (shadow 없음) Card, Table cell
Control — --shadow-xs Button, Input, Checkbox
Raised 10 --shadow-sm Sticky header, Sidebar rail
Overlay 50–100 --shadow-md Select, Popover, Dropdown Menu
Sheet 300 --shadow-lg Sheet content
Modal 300–301 --shadow-lg / ring Alert Dialog, Dialog
Toast 9999 --shadow-lg Sonner toast

Component Shadows

registry·components.css에 적용된 shadow입니다. elevation 레벨보다 낮은 shadow를 쓰지 않습니다.

Focus ring

포커스 링(box-shadow + --color-ring)은 elevation이 아닙니다. 접근성 피드백 전용이며 z-index를 올리지 않습니다.

API Reference

Foundation·컴포넌트 CSS에서 사용하는 shadow·z-index 토큰입니다.

토큰 용도
--shadow-2xs … --shadow-xl 깊이별 box-shadow 스케일
var(--shadow-*) 컴포넌트 box-shadow — 임의 rgba 금지
z-index: 10 Raised — sticky header, sidebar rail
z-index: 50–100 Overlay — dropdown, select, popover
z-index: 300–301 Modal — dialog, sheet, alert dialog
z-index: 9999 Toast — [data-slot="toaster"]
