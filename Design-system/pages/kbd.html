Kbd

키보드 키·단축키를 표시하는 컴포넌트입니다. 버튼, 툴팁, 입력 그룹 등과 함께 사용할 수 있습니다.

Ctrl + B

Group

kbd-group으로 여러 키를 묶어 표시합니다.

Use Ctrl + B Ctrl + K to open the command palette

Button

버튼 안에 Kbd를 넣어 단축키를 함께 표시합니다.

Tooltip

툴팁 안에 단축키를 표시합니다. 툴팁 배경에 맞게 Kbd 색상이 자동 조정됩니다.

Save Changes S
Print Document Ctrl P

Input Group

input-group-addon에 Kbd를 배치해 검색 단축키를 표시합니다.

⌘ K

API Reference

Kbd

data-slot="kbd"는 <kbd> 요소에 적용합니다.

슬롯 요소
kbd <kbd>

KbdGroup

data-slot="kbd-group"으로 여러 Kbd를 그룹화합니다.

슬롯 요소
kbd-group <kbd>
