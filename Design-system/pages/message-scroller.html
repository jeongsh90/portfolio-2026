Keeping Context Visible

Can you explain how scroll anchoring works?
Scroll anchoring keeps the user's reading position stable when content is prepended or inserted above the current scroll position. The browser maintains the visual position of the anchored element even when new content shifts the DOM. This is especially useful for infinite scroll patterns in chat applications.
How does the peek value affect the UX?
The peek value controls how many pixels of the previous message remain visible above the newly anchored user message. A higher value gives more context, while a lower value maximizes space for the AI response. Try adjusting the slider above to see the difference in real time!

Can you explain scroll status tracking?
The component tracks whether the user can scroll up, down, both, or neither and exposes this state via data attributes and hooks.
How is this useful for the UI?
You can update footer status text, show/hide navigation buttons, and provide context about the conversation length. Scroll up and down to watch the header text change above.
That's really useful for accessibility too!
Exactly! Screen readers can announce when the user reaches the top or bottom of the conversation, improving the experience for keyboard and assistive technology users.
