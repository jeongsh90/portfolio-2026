API Reference

Avatar

아바타 이미지와 fallback을 감싸는 루트 컴포넌트입니다.

속성 타입 기본값 설명
data-size "default" | "sm" | "lg" "default" 아바타 크기.
className string — 추가 스타일 클래스.

AvatarImage

아바타 이미지를 표시합니다. Radix Avatar Image props를 모두 지원합니다.

속성 타입 기본값 설명
src string — 이미지 URL.
alt string — 대체 텍스트.
className string — 추가 스타일 클래스.

AvatarFallback

이미지 로드 실패 시 표시되는 대체 콘텐츠입니다.

속성 타입 기본값 설명
data-color "info" | "success" | "warning" | "error" — 시스템 색상을 적용합니다. subtle 배경·텍스트가 함께 지정됩니다.
className string — 추가 스타일 클래스.

AvatarBadge

아바타 우하단에 표시되는 뱃지입니다.

속성 타입 기본값 설명
className string — 색상·크기 등 커스텀 스타일.

AvatarGroup

겹쳐 표시되는 아바타 그룹 컨테이너입니다.

속성 타입 기본값 설명
className string — 추가 스타일 클래스.

AvatarGroupCount

그룹 내 추가 인원 수 또는 아이콘을 표시합니다.

속성 타입 기본값 설명
className string — 추가 스타일 클래스.
