Horizontal

data-orientation="horizontal"인 ScrollBar을 추가하면 가로 스크롤을 사용할 수 있습니다.

API Reference

ScrollArea

data-slot="scroll-area" 루트 요소입니다. 뷰포트와 스크롤바를 감쌉니다.

속성 타입 기본값
tabindex (viewport) number 0

ScrollBar

data-slot="scroll-area-scrollbar" 요소는 스크롤 방향에 따라 세로 또는 가로 스크롤바를 렌더링합니다.

속성 타입 기본값
data-orientation "vertical" | "horizontal" "vertical"
data-state "hidden" —

ScrollAreaThumb

data-slot="scroll-area-thumb" 요소는 스크롤바 트랙 안에서 드래그 가능한 썸(thumb)입니다.

속성 타입 기본값
추가 속성 없음
