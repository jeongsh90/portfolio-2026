Toggle Group

여러 Toggle을 하나의 그룹으로 묶어 단일 또는 다중 선택을 제공하는 컴포넌트입니다.

Outline

data-variant="outline"으로 테두리 스타일을 적용합니다.

Size

data-size prop으로 토글 그룹 크기를 변경합니다. 그룹에 지정하면 하위 항목에 자동 적용됩니다.

Spacing

data-spacing으로 항목 사이 간격을 조정합니다. 기본값은 2이며, 0이면 연결된 그룹 스타일입니다.

Vertical

data-orientation="vertical"로 세로 배치 토글 그룹을 만듭니다.

Disabled

data-disabled="true"로 그룹 전체를 비활성화합니다.

API Reference

ToggleGroup

Radix Toggle Group 기반 루트 컨테이너입니다.

속성 타입 기본값 설명
data-type "single" | "multiple" "single" 단일 또는 다중 선택 모드.
data-variant "default" | "outline" "default" 하위 ToggleGroupItem에 전달되는 variant.
data-size "default" | "sm" | "lg" "default" 하위 항목 크기.
data-spacing "0" | "1" | "2" "2" 항목 간격. 0이면 연결된 그룹 스타일.
data-orientation "horizontal" | "vertical" "horizontal" 배치 방향.
data-disabled "true" | "false" "false" 그룹 전체 비활성화.
data-default-value string — data-type="single"일 때 초기 선택값.
data-default-values string — data-type="multiple"일 때 초기 선택값. |로 구분.

ToggleGroupItem

그룹 내 개별 토글 버튼입니다. Toggle과 동일한 data-state·aria-pressed를 사용합니다.

속성 타입 기본값
data-value string —
data-state "on" | "off" "off"
disabled boolean false
