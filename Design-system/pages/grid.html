Content Inner

[data-slot="content-inner"]가 페이지 그리드의 루트입니다. 문서 페이지는 보통 doc-page-layout으로 전체 12칼럼을 span하고, 내부에서 다시 12칼럼 nested grid를 씁니다.

Responsive Columns

Mobile-first로 data-col-span을 기본값으로 두고, breakpoint에서 data-col-span-md, data-col-span-lg, data-col-span-xl로 덮어씁니다.

< 48rem · base ≥ 48rem · md ≥ 64rem · lg ≥ 80rem · xl

API Reference

Column Span

content-inner 직계 자식에 사용하는 칼럼 span 속성입니다.

속성 Breakpoint 설명
data-col-span="N" All 1–12 칼럼 span (기본)
data-col-span-md="N" ≥ 48rem Tablet 이상 override
data-col-span-lg="N" ≥ 64rem Desktop override
data-col-span-xl="N" ≥ 80rem Wide desktop override

CSS Variables

그리드 레이아웃을 제어하는 CSS 변수입니다.

변수 값 설명
--grid-columns 12 content-inner 칼럼 수
gap calc(var(--spacing) * 4) 그리드 칼럼·행 간격 (content-inner, doc-page-layout)
.doc-page gap: calc(var(--spacing) * 26) 문서 섹션 간격 (margin 미사용)
.doc-pattern-1 gap: calc(var(--spacing) * 6) text-area · component-area 간격
