API Reference

TooltipProvider

앱 루트에 배치해 툴팁 지연 시간 등 전역 설정을 제공합니다. 이 프로젝트에서는 data-delay-duration으로 개별 툴팁에 지정합니다.

속성 타입 기본값 설명
delayDuration number 0 툴팁이 열리기까지의 지연(ms). HTML: data-delay-duration

TooltipContent

툴팁 본문 콘텐츠입니다.

속성 타입 기본값 설명
side "top" | "right" | "bottom" | "left" "top" HTML: data-side
sideOffset number 0 트리거와의 간격(px). HTML: data-side-offset
align "start" | "center" | "end" "center" 트리거 기준 정렬
