API Reference

SidebarProvider

data-slot="sidebar-wrapper" 루트. data-state="expanded" | "collapsed"로 전체 상태를 제어합니다.

속성 타입 기본값 설명
data-state "expanded" | "collapsed" "expanded" 사이드바 펼침·접힘 상태.

Sidebar

data-slot="sidebar" 컨테이너입니다.

속성 타입 기본값 설명
data-variant "sidebar" "sidebar" 사이드바 variant.
data-side "left" | "right" "left" 표시 위치.
data-collapsible "" | "icon" "" 접힘 시 icon 모드.
data-state "expanded" | "collapsed" "expanded" 개별 사이드바 상태.

SidebarMenuButton

메뉴 항목 버튼 또는 링크입니다.

속성 타입 기본값 설명
data-size "default" | "sm" | "lg" "default" 버튼 크기.
data-active "true" | "false" "false" 활성 메뉴 강조.
