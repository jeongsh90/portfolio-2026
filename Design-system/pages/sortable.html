API Reference

Sortable

data-slot="sortable" 루트 컨테이너입니다. SortableJS로 드래그 정렬을 처리합니다.

속성 타입 기본값 설명
data-layout "vertical" | "grid" | "nested" "vertical" 리스트 레이아웃.
data-handle "true" | "false" "true" 핸들로만 드래그할지 여부.
data-group string - 중첩·공유 그룹 이름.

SortableItem

data-slot="sortable-item" 드래그 가능한 항목입니다.

속성 타입 기본값 설명
data-value string - 항목 고유 ID.
data-disabled "true" | "false" "false" 드래그 비활성화.

SortableItemHandle

data-slot="sortable-item-handle" 드래그 핸들 버튼입니다.

속성 타입 기본값 설명
aria-label="Drag to reorder" 권장.
