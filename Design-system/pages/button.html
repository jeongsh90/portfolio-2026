Button

사용자 액션을 트리거하는 버튼 컴포넌트입니다.

Size

data-size prop으로 버튼 크기를 변경합니다.

Default

Outline

Secondary

Ghost

Destructive

data-variant="destructive"는 소프트(은은한 배경) 스타일입니다.

Link

Contained

data-variant="default"(또는 생략) 솔리드 버튼. data-color로 시스템 색상을 적용합니다.

Outlined

data-variant="outline"과 data-color 조합입니다.

Ghost Color

data-variant="ghost"과 data-color 조합입니다.

Soft

data-variant="soft" 소프트 버튼과 data-color 조합입니다.

Color

모든 data-variant와 data-color 조합입니다.

Icon

With Icon

올바른 간격을 위해 아이콘에 data-icon="inline-start" 또는 data-icon="inline-end"를 추가합니다.

Rounded

data-shape="round"(rounded-full)으로 완전히 둥근 버튼을 만듭니다.

Spinner

로딩 상태를 표시하려면 버튼 안에 data-slot="spinner"를 렌더합니다. 간격을 위해 data-icon="inline-start" 또는 data-icon="inline-end"를 추가합니다.

Button Group

버튼 그룹을 만들려면 data-slot="button-group"을 사용합니다. 자세한 내용은 Button Group 문서를 참고하세요.

As Child

asChild prop처럼 다른 요소를 버튼처럼 보이게 하려면 <a>에 data-slot="button"을 적용합니다.

API Reference

Button

다양한 스타일과 기능을 추가하는 button 요소 래퍼입니다.

속성 타입 기본값 설명
data-variant "default" | "outline" | "ghost" | "destructive" | "secondary" | "link" "default" 시각적 스타일 variant.
data-size "default" | "xs" | "sm" | "lg" | "icon" | "icon-xs" | "icon-sm" | "icon-lg" "default" 버튼 크기.
data-color "info" | "success" | "warning" | "error" — 시스템 색상. default, outline, ghost, destructive variant와 조합합니다.
asChild boolean false 자식 요소에 버튼 스타일을 적용합니다. HTML에서는 <a data-slot="button">로 대체합니다.
