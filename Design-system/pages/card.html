API Reference

Card

data-slot="card" 루트 컨테이너입니다.

속성 타입 기본값 설명
data-size "default" | "sm" "default" 패딩·간격(--card-spacing).
data-layout "image" — 커버 이미지 레이아웃(Image 예시).

CardHeader

data-slot="card-header" 제목·설명·액션 영역입니다.

속성 타입 기본값 설명
추가 속성 없음

CardTitle

data-slot="card-title" 카드 제목입니다.

속성 타입 기본값 설명
추가 속성 없음

CardDescription

data-slot="card-description" 제목 아래 설명입니다.

속성 타입 기본값 설명
추가 속성 없음

CardAction

data-slot="card-action" 헤더 우측 상단 액션(버튼·배지 등)입니다.

속성 타입 기본값 설명
추가 속성 없음

CardContent

data-slot="card-content" 본문 영역입니다.

속성 타입 기본값 설명
data-edge "full" — 푸터 위 gap 제거(Edge to Edge 예시).

CardFooter

data-slot="card-footer" 하단 액션 영역입니다.

속성 타입 기본값 설명
data-orientation "vertical" — 세로 버튼 스택(Login 예시).
data-align "end" — 우측 정렬 버튼(Edge to Edge 예시).
