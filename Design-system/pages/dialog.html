API Reference

Dialog

data-slot="dialog" 루트 컨테이너입니다.

속성 타입 기본값 설명
추가 속성 없음

DialogContent

data-slot="dialog-content" 모달 패널입니다.

속성 타입 기본값 설명
data-size "sm" | "md" "sm" 최대 너비(sm: max-w-sm, md: max-w-md).
data-show-close-button "true" | "false" "true" 우측 상단 닫기 버튼 표시.

DialogHeader

data-slot="dialog-header" 제목·설명 영역입니다.

속성 타입 기본값 설명
추가 속성 없음

DialogTitle

data-slot="dialog-title" 다이얼로그 제목입니다.

속성 타입 기본값 설명
추가 속성 없음

DialogDescription

data-slot="dialog-description" 다이얼로그 설명입니다.

속성 타입 기본값 설명
추가 속성 없음

DialogFooter

data-slot="dialog-footer" 하단 액션 영역입니다.

속성 타입 기본값 설명
data-align "start" — 푸터 버튼 좌측 정렬(Custom Close 예시).

DialogClose

data-slot="dialog-close" 다이얼로그를 닫는 버튼입니다.

속성 타입 기본값 설명
data-close-kind "icon" — 우측 상단 아이콘 닫기 버튼.
