API Reference

InputGroup

data-slot="input-group" 루트 컨테이너입니다. input·textarea·addon을 감쌉니다.

속성 타입 기본값 설명
data-disabled "true" — 그룹 전체 비활성화.
role "group" — 접근성 그룹 역할.

InputGroupAddon

data-slot="input-group-addon" 아이콘·텍스트·버튼 등 addon 영역입니다. 포커스 탐색을 위해 input/textarea 뒤에 배치하고 data-align으로 위치를 지정합니다.

속성 타입 기본값 설명
data-align "inline-start" | "inline-end" | "block-start" | "block-end" "inline-start" addon 위치. block은 textarea·세로 레이아웃용.

InputGroupInput

data-slot="input-group-control" input 요소입니다. 그룹 내부 테두리·포커스 링은 루트에서 처리합니다.

속성 타입 기본값 설명
네이티브 <input> 속성을 그대로 사용합니다.

InputGroupTextarea

data-slot="textarea" textarea 요소입니다. block-start / block-end addon과 함께 사용합니다.

속성 타입 기본값 설명
네이티브 <textarea> 속성을 그대로 사용합니다.

InputGroupButton

data-slot="input-group-button" addon 내부 버튼입니다.

속성 타입 기본값 설명
data-size "xs" | "icon-xs" | "sm" | "icon-sm" "icon-xs" 버튼 크기.
data-variant "default" | "destructive" | "outline" | "secondary" | "ghost" | "link" "ghost" 버튼 스타일.

InputGroupText

data-slot="input-group-text" addon 내부 텍스트·라벨입니다.

속성 타입 기본값 설명
추가 속성 없음
