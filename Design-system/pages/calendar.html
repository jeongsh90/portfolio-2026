Calendar

날짜 또는 날짜 범위를 선택할 수 있는 캘린더 컴포넌트입니다.

Basic

기본 캘린더입니다. data-bordered="true"로 테두리를 추가할 수 있습니다.

Range Calendar

data-mode="range"와 data-months="2"로 범위 선택 캘린더를 만듭니다.

Month and Year Selector

data-caption-layout="dropdown"으로 월·연도 드롭다운을 표시합니다.

Presets

프리셋 버튼과 함께 사용해 빠르게 날짜를 선택할 수 있습니다.

Date and Time Picker

캘린더와 시간 입력을 함께 사용합니다.

Booked dates

예약된 날짜를 비활성화하고 취소선으로 표시할 수 있습니다.

Custom Cell Size

data-cell-size로 셀 크기를 조절하고, 셀 안에 추가 정보를 표시할 수 있습니다.

Week Numbers

data-show-week-number="true"로 주차 번호를 표시합니다.

API Reference

Calendar

data-slot="calendar" 루트 요소에 아래 속성을 사용합니다.

속성 타입 기본값
data-mode "single" | "range" "single"
data-months number 1
data-show-outside-days boolean true
data-show-week-number boolean false
data-fixed-weeks boolean false
data-caption-layout "label" | "dropdown" "label"
data-bordered boolean false
data-default-month YYYY-MM 현재 월
data-selected YYYY-MM-DD —
data-range-from YYYY-MM-DD —
data-range-to YYYY-MM-DD —
data-cell-size number (spacing 배수) 8
