Breadcrumb

현재 리소스까지의 경로를 링크 계층으로 표시하는 탐색 컴포넌트입니다.

Custom Separator

data-slot="breadcrumb-separator"의 자식으로 원하는 아이콘이나 문자를 넣어 구분자를 커스터마이징합니다.

  1. 홈
  3. 컴포넌트
  5. Breadcrumb

Dropdown

중간 경로 항목에 드롭다운을 결합해 여러 하위 경로를 한 번에 탐색할 수 있습니다.

  1. 홈
  5. Breadcrumb

Collapsed

경로가 길 때 data-slot="breadcrumb-ellipsis"로 중간 단계를 줄여 표시하고, 드롭다운으로 숨긴 경로를 탐색합니다.

API Reference

Breadcrumb을 구성하는 서브 컴포넌트 목록과 각 속성입니다.

속성 타입 기본값
Breadcrumb — <nav data-slot="breadcrumb" aria-label="breadcrumb">
aria-label string "breadcrumb"
BreadcrumbSeparator — <li data-slot="breadcrumb-separator">
role "presentation" "presentation"
aria-hidden boolean true
자식 요소 icon | string chevron-right
BreadcrumbPage — <span data-slot="breadcrumb-page">
role "link" "link"
aria-disabled boolean true
aria-current "page" "page"
BreadcrumbEllipsis — <span data-slot="breadcrumb-ellipsis">
role "presentation" "presentation"
aria-hidden boolean true
