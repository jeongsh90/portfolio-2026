Typography

data-slot="typography-*" 기반의 타이포그래피 컴포넌트입니다. 제목·본문·인용·목록·코드 등 주요 텍스트 요소의 스타일을 일관되게 제공합니다.

아름다운 타이포그래피는 읽기 전에 느껴진다

타이포그래피는 글자를 배열해 읽기 쉽고 아름답게 만드는 기술입니다. 크기·무게·행간의 비율이 조화를 이룰 때 콘텐츠는 자연스럽게 흐릅니다.

위계와 리듬

명확한 타이포그래피 위계는 독자의 시선을 자연스럽게 안내합니다. 제목은 구조를 만들고, 본문은 깊이를 더하며, 작은 텍스트는 맥락을 보완합니다. 크기와 무게의 대비가 클수록 위계는 뚜렷해집니다.

“타이포그래피의 목적은 독자가 읽고 있다는 사실을 잊게 만드는 것이다.”

비율과 여백

텍스트와 여백의 비율은 페이지의 호흡을 결정합니다. 황금 비율과 모듈러 스케일을 활용하면 어떤 크기 조합도 자연스럽게 어울립니다.

  • 행간은 폰트 크기의 1.4–1.6배가 가장 읽기 편합니다
  • 제목 간격은 본문 행간보다 넓게 설정합니다
  • 자간은 크기가 클수록 줄이는 것이 자연스럽습니다

세부 조정

세부 수준에서의 타이포그래피는 미묘하지만 결정적입니다. font-feature-settings로 합자와 수치 스타일을 제어하면 텍스트의 완성도가 높아집니다.

본문 텍스트의 최적 너비는 약 60–75자(ch)입니다. 너무 길면 시선이 피로해지고, 너무 짧으면 리듬이 끊깁니다.

API Reference

Typography

data-slot="typography-*" 슬롯을 HTML 요소에 적용해 타이포그래피 스타일을 사용합니다.

슬롯 엘리먼트 설명
typography-specimen <div> Overview specimen 레이아웃 루트
specimen-pair <div> specimen 내 콘텐츠 그룹. data-pair="hero" | "section" | "subsection" | "detail"
typography <div> 프로즈 컨테이너. 하위 요소 간 간격 규칙 적용
typography-title <h1> 문서 제목. typography-h1과 동일 스타일
typography-h1 <h1> 1단계 제목 (가운데 정렬)
typography-h2 <h2> 2단계 제목
typography-h3 <h3> 3단계 제목
typography-h4 <h4> 4단계 제목
typography-p <p> 본문 단락
typography-lead <p> 도입부(리드) 텍스트
typography-muted <p> 보조·흐린 텍스트
typography-large <div> 강조된 큰 텍스트
typography-small <small> 작은 텍스트
typography-blockquote <blockquote> 인용문
typography-list <ul> 순서 없는 목록
typography-link <a> 링크
typography-inline-code <code> 인라인 코드
typography-table-wrap <div> 테이블 가로 스크롤 래퍼
typography-table <table> 프로즈 내 테이블
