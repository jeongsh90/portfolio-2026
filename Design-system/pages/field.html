API Reference

Field

단일 필드 래퍼. role="group"과 함께 사용합니다.

속성 타입 기본값 설명
data-orientation "vertical" | "horizontal" | "responsive" "vertical" 라벨·컨트롤 배치 방향
data-invalid boolean — 전체 필드 오류 스타일
data-disabled boolean — 비활성 스타일 (자식 :disabled와 함께 사용)

FieldSet

슬롯 엘리먼트 설명
field-set <fieldset> 관련 필드 그룹 컨테이너
field-legend <legend> data-variant="label"로 라벨 크기 정렬
field-group <div> Field 스택·container query 부모
field-label <label> 필드 라벨. data-weight="normal", data-choice-card="true" 지원
field-content <div> 가로 레이아웃에서 라벨·설명 묶음
field-description <p> 보조 설명 텍스트
field-error <p> 검증 오류 메시지 (role="alert")
field-separator <div> FieldGroup 내 섹션 구분선
field-row <div> 라벨·부가 UI를 양쪽 정렬
