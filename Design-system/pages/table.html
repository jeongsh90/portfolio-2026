Table

테이블의 루트 요소입니다. 모든 하위 슬롯을 감쌉니다.

슬롯 엘리먼트 설명
table <table> 테이블 루트
table-header <thead> 헤더 그룹
table-body <tbody> 바디 그룹
table-footer <tfoot> 푸터 그룹
table-row <tr> 테이블 행. data-state="selected" 지원
table-head <th> 헤더 셀. data-align="right" 지원
table-cell <td> 바디 셀. data-align="right" 지원
table-caption <caption> 테이블 하단에 렌더링되는 캡션
