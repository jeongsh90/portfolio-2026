API Reference

Marker

마커 루트입니다. div, a, button 어느 태그에도 data-slot="marker"를 적용할 수 있습니다.

속성타입기본값설명
data-variant"default" | "separator" | "border""default"마커 스타일 변형.
data-layout"col"—아이콘을 텍스트 위에 세로로 쌓는 레이아웃.
data-shimmer"true"—마커 전체에 shimmer 애니메이션 적용.
classstring—추가 스타일 클래스.

MarkerIcon

장식용 아이콘 슬롯입니다. 스크린 리더에서 숨겨집니다(aria-hidden="true").

속성타입기본값설명
aria-hidden"true"—보조 기술에서 숨김 (필수).
classstring—추가 스타일 클래스.

MarkerContent

마커의 텍스트·콘텐츠 영역입니다.

속성타입기본값설명
data-shimmer"true"—콘텐츠에만 shimmer 애니메이션 적용 (스피너는 제외).
classstring—추가 스타일 클래스.
