API Reference

ResizablePanelGroup

data-slot="resizable-panel-group" 패널 그룹 루트입니다.

속성 타입 기본값 설명
data-orientation "horizontal" | "vertical" "horizontal" 패널 배치·리사이즈 방향.

ResizablePanel

data-slot="resizable-panel" 크기 조절 가능한 패널입니다.

속성 타입 기본값 설명
data-default-size string — 초기 크기(퍼센트). 예: 50%.
data-size string — 현재 크기. JS가 동기화합니다.
data-min-size string 10% 최소 크기(퍼센트).

ResizableHandle

data-slot="resizable-handle" 패널 사이 드래그 핸들입니다.

속성 타입 기본값 설명
data-with-handle "true" | "false" "false" 그립 아이콘 핸들 표시.
aria-orientation "horizontal" | "vertical" — JS가 그룹 방향에 맞춰 설정합니다.
