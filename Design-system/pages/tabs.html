Line

TabsList에 variant="line"을 지정하면 라인 스타일 탭을 사용할 수 있습니다.

Vertical

orientation="vertical"로 세로 탭을 사용합니다.

Disabled

disabled 속성으로 탭 트리거를 비활성화합니다.

Icons

아이콘과 텍스트를 함께 사용하는 탭 트리거입니다.

API Reference

Tabs

data-slot="tabs" 루트 요소입니다.

속성 타입 기본값
data-default-value string —
data-orientation "horizontal" | "vertical" "horizontal"
data-value string —

TabsList

data-slot="tabs-list" 요소는 role="tablist"과 함께 사용합니다.

속성 타입 기본값
data-variant "default" | "line" "default"
role "tablist" "tablist"
aria-orientation "horizontal" | "vertical" —

TabsTrigger

data-slot="tabs-trigger" 요소는 role="tab"과 함께 사용합니다.

속성 타입 기본값
data-value string —
data-state "active" | "inactive" "inactive"
aria-selected "true" | "false" "false"
disabled boolean false

TabsContent

data-slot="tabs-content" 요소는 role="tabpanel"과 함께 사용합니다.

속성 타입 기본값
data-value string —
data-state "active" | "inactive" "inactive"
aria-labelledby string —
