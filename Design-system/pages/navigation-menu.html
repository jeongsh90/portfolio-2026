API Reference

NavigationMenu

data-slot="navigation-menu" 루트 컨테이너입니다.

속성 타입 기본값
data-viewport "true" | "false" "true"

NavigationMenuTrigger

data-slot="navigation-menu-trigger" 패널을 여는 트리거입니다.

속성 타입 기본값
data-state "open" | "closed" "closed"

NavigationMenuLink

최상위 링크 또는 패널 내 링크 카드에 사용합니다.

속성 타입 기본값
