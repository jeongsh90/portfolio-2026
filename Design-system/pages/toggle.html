Toggle

두 가지 상태를 전환하는 버튼형 컨트롤입니다. 서식 도구, 북마크, 필터 등 on/off 동작에 사용합니다.

Outline

data-variant="outline"으로 테두리 스타일을 적용합니다.

With Text

아이콘과 텍스트 레이블을 함께 표시합니다.

Size

data-size 속성으로 크기를 조정합니다. sm, default, lg를 지원합니다.

Disabled

disabled 속성으로 토글을 비활성화합니다.

API Reference

Toggle

Radix Toggle 기반의 두 상태 버튼입니다.

속성 타입 기본값 설명
data-variant "default" | "outline" "default" 시각적 스타일 variant.
data-size "default" | "sm" | "lg" "default" 토글 크기.
data-state "on" | "off" "off" 눌림 상태. JS가 aria-pressed와 함께 동기화합니다.
aria-pressed "true" | "false" "false" 접근성용 눌림 상태.
disabled boolean false 비활성화 여부.
aria-invalid "true" | "false" — 유효하지 않음 상태. 파괴적 테두리·링을 표시합니다.
