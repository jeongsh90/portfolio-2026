API Reference

Progress

Radix Progress 기반 루트 트랙입니다. role="progressbar"를 사용합니다.

속성 타입 기본값 설명
data-value number 0 현재 진행 값.
data-min number 0 최솟값.
data-max number 100 최댓값.
aria-valuenow number — JS가 data-value와 동기화.
aria-valuemin number 0 최솟값.
aria-valuemax number 100 최댓값.

ProgressIndicator

data-slot="progress-indicator" 채워진 진행 영역입니다.

속성 타입 기본값 설명
추가 속성 없음. transform은 JS가 값에 맞춰 설정합니다.
