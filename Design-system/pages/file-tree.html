File Tree

중첩된 Collapsible로 폴더·파일 탐색기 UI를 구성합니다. 폴더는 닫힘·열림 상태에 따라 folder / folder-open 아이콘이 전환됩니다.

Basic

카드 없이 data-slot="file-tree"만 사용하는 최소 예시입니다. chevron·폴더·파일 아이콘은 모두 size-4(16px)로 맞춥니다.

API Reference

FileTree

파일 트리 루트 컨테이너입니다. 폴더는 Collapsible(data-variant="tree"), 파일은 file-tree-file로 구성합니다.

슬롯 설명
file-tree 트리 루트. 세로 gap-1 스택
file-tree-folder-icon 폴더 아이콘 래퍼. folder(닫힘) / folder-open(열림) 전환
file-tree-file-icon 파일 아이콘 래퍼 (file, 16px)
file-tree-file 리프 파일 행 버튼
file-tree-label 폴더·파일 이름 텍스트

Folder (Collapsible)

폴더 노드는 collapsible-trigger(data-variant="tree") + collapsible-content 조합입니다. initCollapsibles()가 토글을 처리합니다.

속성 설명
data-variant="tree" 트리 트리거·들여쓰기 스타일
data-default-open 초기 펼침 상태
data-state open일 때 chevron 90° 회전 + folder-open 표시
