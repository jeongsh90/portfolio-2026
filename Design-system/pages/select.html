API Reference

Select

data-slot="combobox"에 data-mode="select"를 지정한 루트입니다. Combobox와 동일한 마크업·옵션 스타일을 쓰며 입력은 readonly로 고정합니다.

속성 타입 기본값 설명
data-mode "select" — 검색 없이 선택만 허용하는 Select 모드. 필수입니다.
data-default-value string — 초기 선택값. ComboboxItem의 data-value와 일치해야 합니다.
disabled boolean false ComboboxInput·트리거 버튼에 적용해 비활성화합니다.
aria-invalid "true" | "false" — 유효하지 않음 상태. 입력에 파괴적 테두리·링을 표시합니다.

ComboboxItem

드롭다운 목록의 개별 옵션입니다. Combobox와 동일한 data-slot="combobox-item"·체크 표시 스타일을 사용합니다.

속성 타입 기본값
data-value string —
data-disabled "true" | "false" "false"
