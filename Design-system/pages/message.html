Message

대화 내 단일 메시지를 표시하는 컴포넌트입니다. 아바타·헤더·푸터·정렬을 선택적으로 조합할 수 있으며, AI 응답·추론 단계·툴 호출을 표현하는 데 최적화되어 있습니다. 메시지 표면은 Bubble 컴포넌트로 렌더링합니다.

AI
How can I help you today?
ME
I need help building a design system.
AI
Great! A design system typically includes tokens, components, and documentation. Where would you like to start?

Avatar

MessageAvatar는 메시지 하단에 앵커링됩니다. data-align="end"일 때 아바타는 오른쪽, data-align="start"일 때 왼쪽에 위치합니다. 슬롯을 비워두면 공간만 예약되어 그룹 내 정렬이 유지됩니다.

AI
This message has an avatar on the left.
ME
This message has an avatar on the right.

Group

MessageGroup으로 같은 발신자의 연속 메시지를 묶습니다. 첫 번째 메시지에만 아바타를 표시하고, 이후 메시지의 MessageAvatar는 비워두어 정렬 공간만 확보합니다.

AI
Here are three things to consider.
First, define your design tokens clearly.
Second, keep component APIs consistent.
ME
That makes sense!
What's the third thing?

Header and Footer

MessageHeader는 발신자 이름을, MessageFooter는 타임스탬프·읽음 상태 등 메타데이터를 표시합니다. 두 슬롯 모두 선택적입니다.

AI
Assistant · 2:34 PM
This message has both a header and a footer. The header shows the sender name and time.
Delivered
ME
You · 2:35 PM
Thank you! This layout is very clean.
Read

Actions

MessageFooter에 액션 버튼을 배치합니다. 복사·재시도·피드백 등 메시지 레벨의 인터랙션을 제공합니다.

AI
Design tokens are the single source of truth for your visual style — colors, spacing, typography, and more.
AI
They help maintain consistency across platforms and teams.

Attachment

이미지·파일 첨부물은 message-content 안에서 bubble과 나란히 배치합니다. bubble-content 밖에 두어야 정렬 색상 상속을 피할 수 있습니다.

ME
Here's the screenshot you asked for.
AI
I've attached the design specification document.
design-spec-v2.pdf 2.4 MB · PDF
ME
budget-q3.xlsx 840 KB · Excel
banner.png 1.2 MB · PNG

API Reference

Message

대화 행 레이아웃 루트입니다. 아바타·정렬·헤더·푸터를 소유합니다.

속성타입기본값설명
data-align"start" | "end""start"메시지 정렬 방향. start = 좌(AI), end = 우(사용자).
classstring—추가 스타일 클래스.

MessageGroup

같은 발신자의 연속 메시지를 묶는 컨테이너입니다.

속성타입기본값설명
classstring—추가 스타일 클래스.

MessageAvatar

메시지 하단에 앵커링되는 아바타 슬롯입니다. 비워두면 그룹 정렬용 공간만 예약합니다.

속성타입기본값설명
classstring—추가 스타일 클래스.

MessageContent

헤더·Bubble·푸터를 세로로 쌓는 래퍼입니다.

속성타입기본값설명
classstring—추가 스타일 클래스.

MessageHeader

발신자 이름·시간 등 메시지 상단 메타데이터를 표시합니다.

속성타입기본값설명
classstring—추가 스타일 클래스.

MessageFooter

타임스탬프·읽음 상태·액션 버튼 등 메시지 하단 콘텐츠를 담습니다.

속성타입기본값설명
classstring—추가 스타일 클래스.

Bubble

메시지의 시각적 표면입니다. Message 없이 단독으로도 사용할 수 있습니다.

속성타입기본값설명
classstring—추가 스타일 클래스.

BubbleContent

버블의 실제 콘텐츠 영역입니다. 패딩·배경색·border-radius가 적용됩니다.

속성타입기본값설명
classstring—추가 스타일 클래스.

MessageAction

MessageFooter 안에 배치하는 icon-sm 크기의 ghost 스타일 액션 버튼입니다.

속성타입기본값설명
data-active"true" | "false"—활성 상태 (thumbs up/down 등). true이면 primary 색상.
aria-labelstring—접근성 레이블 (필수).
classstring—추가 스타일 클래스.
