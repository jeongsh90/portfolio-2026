Switch

체크됨과 체크 해제 사이를 전환할 수 있는 컨트롤입니다.

Description

FieldContent와 FieldDescription으로 보조 설명을 추가합니다.

Focus is shared across devices, and turns off when you leave the app.

Choice Card

FieldLabel이 카드 전체를 감싸 클릭 가능한 카드 패턴을 만듭니다.

Disabled

disabled 속성으로 스위치를 비활성화합니다.

Invalid

aria-invalid 속성으로 유효하지 않음 상태를 나타냅니다.

You must accept the terms and conditions to continue.

Size

data-size 속성으로 크기를 조정합니다. sm과 default를 지원합니다.

API Reference

Switch

data-slot="switch" 요소는 role="switch"와 함께 사용합니다.

속성 타입 기본값 설명
role "switch" "switch" ARIA 역할. 반드시 명시한다.
aria-checked "true" | "false" "false" 스위치의 체크 상태.
data-state "checked" | "unchecked" "unchecked" CSS 상태 스타일링용 데이터 속성.
data-size "default" | "sm" "default" 스위치 크기.
disabled boolean — 비활성화 여부. 클릭 및 키보드 인터랙션을 막는다.
aria-invalid "true" | "false" — 유효하지 않음 상태. 파괴적 테두리·링을 표시한다.
id string — <label for>와 연결하기 위한 고유 ID.
