Sheet

Dialog를 확장해 화면 가장자리에서 슬라이드되는 패널로 보조 콘텐츠를 표시하는 sheet 컴포넌트입니다.

Side

SheetContent의 side prop으로 sheet가 나타날 화면 가장자리를 지정합니다. 값은 top, right, bottom, left입니다.

No Close Button

SheetContent에 showCloseButton={false}를 지정하면 닫기 버튼을 숨깁니다.

No Close Button

This sheet doesn't have a close button in the top-right corner. Click outside to close.

API Reference

SheetContent

data-slot="sheet-content" 요소는 role="dialog"과 함께 사용합니다.

속성 타입 기본값
data-side "top" | "right" | "bottom" | "left" "right"
data-show-close-button boolean true
role "dialog" "dialog"
aria-modal "true" "true"
aria-labelledby string —
aria-describedby string —

SheetClose

data-slot="sheet-close" 요소를 클릭하면 sheet가 닫힙니다.

속성 타입 기본값
data-close-kind "icon" —
data-sheet-close boolean —
