Sorting

헤더의 data-sort-column 버튼으로 열을 오름·내림차순 정렬합니다. 같은 열을 다시 클릭하면 방향이 전환됩니다.

Filtering

data-table-filter 입력으로 이메일 열을 실시간 필터링합니다. 필터 변경 시 첫 페이지로 이동합니다.

Pagination

data-page-size로 페이지당 행 수를 지정하고, 푸터의 Previous / Next 버튼으로 페이지를 이동합니다.

API Reference

Data Table

data-slot="data-table" 래퍼에 기능 플래그와 페이지 크기를 지정합니다. tbody는 initDataTables()가 채웁니다.

속성 타입 기본값 설명
data-features string 전체 기능 쉼표 구분: filter, sort, pagination, visibility, selection, actions
data-page-size number 5 페이지당 행 수
data-table-filter input — 이메일 필터 입력 (data-feature="filter")
data-sort-column string — 정렬 대상 열 키 (헤더 버튼)
data-column-toggle string — 열 표시 토글 대상 (data-column과 일치)
data-column string — 헤더·셀 열 식별자 (visibility 연동)
data-action "prev" | "next" — 페이지네이션 버튼
data-feature string — 비활성 기능 UI에 hidden 적용

Slots

슬롯 엘리먼트 설명
data-table <div> 루트 래퍼 (toolbar · table · footer)
data-table-toolbar <div> 필터·열 토글 등 상단 도구
data-table-footer <div> 선택 정보·페이지네이션
data-table-selection-info <span> 선택 행 수 텍스트
data-table-pagination <div> Previous / Next 버튼 그룹
data-table-head-button <button> 정렬 가능 헤더 버튼
