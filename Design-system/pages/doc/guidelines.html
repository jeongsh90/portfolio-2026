Guidelines

이 디자인 시스템의 CSS 변수·컴포넌트 속성·레이아웃 규칙 사용법을 안내합니다. 모든 컴포넌트는 아래 규칙을 따릅니다.

CSS Tokens

하드코딩된 색상·크기 값 대신 시맨틱 CSS 변수를 사용합니다. 라이트/다크 테마 전환이 자동으로 반영됩니다.

Color

배경·텍스트·인터랙션 색상 토큰입니다. 직접 팔레트 값(--color-blue-500)을 쓰지 않고 시맨틱 토큰을 참조합니다.

변수 용도
--color-background 페이지 기본 배경
--color-foreground 기본 본문 텍스트
--color-card 카드·패널 배경
--color-card-foreground 카드 위 텍스트
--color-primary 주요 액션 색상 (버튼 default, 링크)
--color-primary-foreground primary 배경 위 텍스트
--color-muted 보조 배경, 비활성 영역
--color-muted-foreground 보조 텍스트, 플레이스홀더, 힌트
--color-accent hover 강조 배경
--color-accent-foreground accent 배경 위 텍스트
--color-border 테두리 기본값
--color-input 인풋 필드 테두리
--color-ring 포커스 아웃라인(링)
--color-destructive 삭제·위험 액션 색상
--color-destructive-foreground destructive 배경 위 텍스트

Spacing

기본 단위는 --spacing = 0.25rem (4px). calc(var(--spacing) * N) 형태만 사용하고 임의의 픽셀 값은 쓰지 않습니다.

표현식 값 주요 용도
calc(var(--spacing) * 1) 4px 아이콘 보조 여백, 미세 간격
calc(var(--spacing) * 2) 8px 패딩 sm, 인라인 gap
calc(var(--spacing) * 3) 12px 패딩 기본, 컴팩트 간격
calc(var(--spacing) * 4) 16px 그리드 gap, 패딩 default
calc(var(--spacing) * 6) 24px doc-pattern-1 내부 gap
calc(var(--spacing) * 8) 32px 컴포넌트 높이 기본 (버튼, 메뉴)
calc(var(--spacing) * 14) 56px 헤더·사이드바 헤더 높이
calc(var(--spacing) * 26) 104px doc-page 섹션 간 gap

Typography

폰트 크기·굵기·행간·자간은 변수 조합으로 지정합니다. font shorthand를 사용하면 간결하게 쓸 수 있습니다.

카테고리 변수 값
Font family --font-sans Pretendard (기본 본문)
Font family --font-mono 코드·데이터 표시
Size --text-xs 0.75rem · 12px
Size --text-sm 0.875rem · 14px
Size --text-base 1rem · 16px
Size --text-lg 1.125rem · 18px
Size --text-xl ~ --text-5xl 1.25rem ~ 3rem (헤딩)
Weight --font-weight-normal 400 · 본문
Weight --font-weight-medium 500 · 레이블, 코드
Weight --font-weight-semibold 600 · 소제목, 버튼
Weight --font-weight-bold 700 · 헤딩
Line height --leading-normal 1.5 · 일반 본문
Line height --leading-normal-lg 1.75rem · 서술형 문장
Letter spacing --tracking-sm -0.008em · 소제목
Letter spacing --tracking-base -0.01em · 본문 (Pretendard 권장)
Letter spacing --tracking-normal 0em · 코드, 영문

Border Radius

--radius 기본값을 기준으로 배수로 계산됩니다. 컴포넌트 크기에 따라 적합한 단계를 선택합니다.

변수 계산식 용도
--radius-sm calc(var(--radius) * .6) 배지, 태그, 보조 요소
--radius-md calc(var(--radius) * .8) 버튼, 인풋, 셀렉트
--radius-lg var(--radius) 카드, 드롭다운, 팝오버
--radius-xl calc(var(--radius) * 1.4) 모달, 시트, 사이드바 컨테이너
--radius-2xl calc(var(--radius) * 1.8) 대형 카드, 전체 섹션

Transition

애니메이션은 공통 변수를 사용해 속도·이징을 통일합니다.

변수 값 설명
--default-transition-duration .15s 기본 전환 시간
--default-transition-timing-function cubic-bezier(.4, 0, .2, 1) 기본 이징 (ease-in-out 계열)

Component Attributes

컴포넌트는 data-slot으로 역할을 선언하고 data-variant · data-size · data-state로 상태를 제어합니다.

data-slot

모든 컴포넌트 요소는 data-slot으로 의미를 선언합니다. CSS는 이 속성을 선택자로 사용해 스타일을 적용합니다.

값 역할
"button" 버튼 루트 요소
"card" 카드 컨테이너
"card-header" / "card-content" / "card-footer" 카드 구역 분리
"label" 폼 레이블
"icon" 아이콘 래퍼
"badge" 배지
"separator" 구분선
"tooltip" 툴팁 컨테이너
"tooltip-content" 툴팁 내용
"dialog" / "dialog-content" 다이얼로그 루트 / 패널
"sheet" / "sheet-content" 시트 루트 / 패널
"accordion" / "accordion-item" 아코디언 루트 / 항목
"accordion-trigger" / "accordion-content" 아코디언 토글 버튼 / 패널
"tabs" / "tabs-list" / "tabs-trigger" / "tabs-content" 탭 구조
"sidebar" / "sidebar-wrapper" 사이드바 패널 / 전체 래퍼

data-variant

시각적 스타일 변형을 선택합니다. 컴포넌트마다 지원 variant가 다릅니다.

값 설명 주요 사용
"default" 채운 스타일 (primary 배경) Button, Badge
"outline" 테두리만 있는 스타일 Button, Badge, Input
"ghost" 투명 배경, hover 시 강조 Button, Toggle
"secondary" muted 배경의 보조 스타일 Button, Badge
"destructive" 위험·삭제 액션 Button, Alert
"link" 텍스트 링크 스타일 Button

data-size

컴포넌트의 크기를 조절합니다.

값 설명
"xs" Extra small — 최소 크기
"sm" Small — 컴팩트 UI
"default" 기본 크기 (생략 가능)
"lg" Large — 강조 액션
"icon" 정방형 아이콘 버튼
"icon-sm" / "icon-lg" 작은/큰 아이콘 버튼

data-state

컴포넌트의 현재 상태를 나타냅니다. JavaScript가 자동으로 토글하며 CSS 선택자로 스타일링에 사용됩니다.

값 설명 주요 사용
"open" / "closed" 열림/닫힘 Accordion, Collapsible, Dialog, Sheet, Tooltip
"expanded" / "collapsed" 펼침/접힘 Sidebar
"checked" / "unchecked" 선택됨/해제됨 Checkbox, Switch, Toggle
"active" 현재 활성 항목 Tabs, Nav
"loading" 로딩 중 Button, Skeleton
"disabled" 비활성 Button, Input, Select
"error" 유효성 오류 Input, Field

data-color

시스템 색상을 적용합니다. data-variant와 조합해 사용합니다.

값 설명 토큰 접두사
"info" 정보·안내 --sys-info-*
"success" 성공·완료 --sys-success-*
"warning" 경고·주의 --sys-warning-*
"error" 오류·실패 --sys-error-*

Layout

페이지는 12칼럼 그리드를 기반으로 구성됩니다. 문서 페이지는 doc-page-layout → doc-page → doc-pattern-1 구조를 따릅니다.

Page Structure

문서 페이지를 구성하는 래퍼 계층입니다.

클래스 / 속성 역할
.doc-page-layout 페이지 + 우측 page-nav를 나란히 배치하는 최외곽 래퍼
.doc-page 섹션들을 세로로 나열하는 gap: calc(var(--spacing) * 26) flex 컬럼
.doc-pattern-1 text-area + component-area(또는 reference-area)를 gap: calc(var(--spacing) * 6)으로 배치
[data-slot="text-area"] h2/h3 + desc 텍스트 블록
[data-slot="component-area"] 인터랙티브 컴포넌트 프리뷰 영역
[data-slot="reference-area"] API 테이블 래퍼 (border + border-radius)
[data-slot="page-nav"] 우측 온페이지 네비게이션

Column Span

content-inner의 직계 자식에 적용하는 12칼럼 span 속성입니다. 합이 12를 넘으면 다음 줄로 내려갑니다.

속성 Breakpoint 설명
data-col-span="N" All 1–12 칼럼 span (기본)
data-col-span-md="N" ≥ 48rem Tablet 이상 override
data-col-span-lg="N" ≥ 64rem Desktop override
data-col-span-xl="N" ≥ 80rem Wide desktop override
