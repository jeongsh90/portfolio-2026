AI Prompt

이 디자인 시스템의 컴포넌트를 다른 프로젝트에서 활용하기 위한 AI 전용 가이드입니다. 셋업 방법, 정확한 컴포넌트 HTML 마크업, CSS 변수 커스터마이징 방법을 담고 있습니다. 이 문서에 명시된 마크업 패턴을 그대로 사용하세요.

컴포넌트 JS 동작 구현 기준

각 컴포넌트의 인터랙션은 HTML 속성을 읽고 쓰는 방식입니다. 외부에서 동일하게 구현할 때 아래 기준을 따릅니다.

컴포넌트 JS가 해야 할 일
Accordion accordion-trigger 클릭 → 부모 accordion-item의 data-state를 open/closed 토글. data-type="single"이면 다른 항목 닫기
Tabs tabs-trigger 클릭 → 해당 data-value를 가진 tabs-content만 표시, 나머지 hidden. 트리거에 data-state="active" 토글
Dialog dialog-trigger 클릭 → dialog-content의 aria-hidden 제거, dialog-overlay 표시. data-dialog-close 버튼·오버레이 클릭·Esc로 닫기. 포커스 트랩 구현
Combobox / Select 트리거 클릭 → combobox-content의 data-state를 open/closed 토글. 항목 클릭 → combobox-input 값 업데이트, 패널 닫기
Checkbox 클릭 → aria-checked와 data-checked 토글 (true/false)
Switch 클릭 → aria-checked와 data-state 토글 (checked/unchecked)

HTML 기본 골격

외부 프로젝트의 최소 HTML 뼈대입니다. <body> 안에 컴포넌트를 자유롭게 배치합니다.

위치 코드
<html> <html lang="ko"> — 다크모드 시: <html lang="ko" class="dark">
<head> 필수 <meta charset="UTF-8">, <meta name="viewport" content="width=device-width, initial-scale=1.0">
Lucide 초기화 document.addEventListener('DOMContentLoaded', () => lucide.createIcons())

핵심 개념: data-slot 시스템

이 디자인 시스템은 CSS 클래스 대신 data-slot HTML 속성을 CSS 선택자로 사용합니다. 컴포넌트의 각 부분에 data-slot="역할이름"을 선언하면 스타일이 자동 적용됩니다. 임의의 클래스를 추가하지 마세요.

속성 역할 예시
data-slot="컴포넌트명" 컴포넌트 루트 스타일 적용 data-slot="button", data-slot="card"
data-variant="값" 시각적 변형 선택 data-variant="outline", data-variant="destructive"
data-size="값" 크기 조절 data-size="sm", data-size="lg", data-size="icon"
data-state="값" JS가 관리하는 인터랙션 상태 data-state="open", data-state="checked"
data-orientation="값" 배치 방향 data-orientation="horizontal"

컴포넌트 마크업

각 컴포넌트의 정확한 HTML 마크업입니다. 아래 패턴을 정확히 따르면 별도 CSS 없이 스타일이 적용됩니다.

Button

type 속성 필수. 아이콘 전용 버튼은 aria-label 필수.

용도 마크업
Default (primary 배경) <button type="button" data-slot="button">저장</button>
Outline <button type="button" data-slot="button" data-variant="outline">취소</button>
Secondary <button type="button" data-slot="button" data-variant="secondary">보조</button>
Ghost <button type="button" data-slot="button" data-variant="ghost">더보기</button>
Destructive <button type="button" data-slot="button" data-variant="destructive">삭제</button>
Link <button type="button" data-slot="button" data-variant="link">링크</button>
Small data-size="sm" 추가
Large data-size="lg" 추가
아이콘 버튼 <button type="button" data-slot="button" data-variant="outline" data-size="icon" aria-label="닫기"><i data-lucide="x" aria-hidden="true"></i></button>
아이콘 + 텍스트 <button type="button" data-slot="button"><i data-lucide="plus" aria-hidden="true"></i> 추가</button>
비활성 disabled 속성 추가
Submit type="submit" 사용

Badge

상태·라벨 표시. 클릭 없는 순수 표시 요소이므로 <span> 사용.

용도 마크업
Default <span data-slot="badge">라벨</span>
Secondary <span data-slot="badge" data-variant="secondary">라벨</span>
Destructive <span data-slot="badge" data-variant="destructive">오류</span>
Outline <span data-slot="badge" data-variant="outline">라벨</span>
아이콘 왼쪽 <span data-slot="badge" data-variant="secondary"><i data-lucide="check" data-icon="inline-start" aria-hidden="true"></i>완료</span>
아이콘 오른쪽 <span data-slot="badge" data-variant="outline">라벨<i data-lucide="arrow-right" data-icon="inline-end" aria-hidden="true"></i></span>

Card

제목·내용·액션을 담는 패널. header → content → footer 순서를 따릅니다.

data-slot HTML 요소 설명
card <div> 카드 루트. data-size="sm"으로 컴팩트 간격
card-header <div> 제목·설명·우측 액션 포함
card-title <div> 카드 제목 (<h*> 아님)
card-description <div> 카드 부제목
card-action <div> 헤더 우측 버튼 영역
card-content <div> 주요 콘텐츠. data-edge="full"로 가장자리 확장
card-footer <div> 하단 버튼 영역. data-orientation="vertical"로 세로 배치

Input & Field

<label>의 for와 <input>의 id는 반드시 쌍을 맞춥니다.

패턴 마크업
단순 입력 <input type="text" data-slot="input" placeholder="입력">
라벨 + 입력 <div data-slot="field" role="group"><label data-slot="field-label" for="my-id">이름</label><input type="text" id="my-id" data-slot="input"></div>
설명 추가 field 안에 <p data-slot="field-description">설명</p> 추가
오류 상태 input에 data-state="error" + <p data-slot="field-message">오류</p>
여러 필드 묶음 <div data-slot="field-group">로 여러 field 감싸기
가로 배치 (체크박스·스위치용) <div data-slot="field" data-orientation="horizontal">
Textarea <textarea data-slot="textarea" rows="4"></textarea>

Alert

아이콘은 alert 직계 첫 자식으로 래퍼 없이 배치합니다. alert-title과 alert-description은 <div>를 사용합니다.

변형 마크업
기본 (안내) <div data-slot="alert"><i data-lucide="info" aria-hidden="true"></i><div data-slot="alert-title">제목</div><div data-slot="alert-description"><p>내용</p></div></div>
Destructive (오류) <div data-slot="alert" data-variant="destructive"><i data-lucide="circle-alert" aria-hidden="true"></i>…</div>

Accordion

data-type="single"은 한 번에 하나만, data-type="multiple"은 여러 개 동시에 열 수 있습니다. data-default-value로 초기 열린 항목을 지정합니다.

data-slot 속성 설명
accordion data-type="single", data-collapsible, data-default-value="item-1" 루트 컨테이너. data-size="lg"로 넓은 간격
accordion-item data-value="item-1" 각 항목 래퍼. value는 default-value와 일치시킴
accordion-header — <h3> 요소 사용 (시맨틱 헤딩)
accordion-trigger type="button" 토글 버튼. 내부에 <span data-slot="accordion-trigger-icon"><i data-lucide="chevron-down"></i></span> 포함
accordion-content — 펼쳐지는 영역. 안에 <div data-slot="accordion-content-inner">로 내용 감싸기

Tabs

data-default-value로 초기 탭을 지정합니다. 트리거와 콘텐츠의 data-value가 일치해야 JS가 연결합니다.

data-slot 속성 설명
tabs data-default-value="탭키" 루트. 초기 활성 탭 지정
tabs-list data-variant="line" (선택) 탭 버튼 목록. data-variant="line"으로 라인 스타일
tabs-trigger type="button", data-value="탭키" 각 탭 버튼. JS가 활성 탭에 data-state="active" 토글
tabs-content data-value="탭키" 각 탭 패널. 비활성 패널은 JS가 hidden 적용

Dialog

dialog-trigger 안의 버튼 클릭으로 열립니다. 닫기는 data-dialog-close 속성을 버튼에 추가하거나 오버레이 클릭·Esc 키로 가능합니다.

data-slot 속성 설명
dialog — 전체 래퍼. trigger + overlay + content를 직계 자식으로 포함
dialog-trigger — <div> 래퍼. 안에 aria-haspopup="dialog" aria-expanded="false" 버튼 배치
dialog-overlay aria-hidden="true" 배경 어두운 오버레이
dialog-content data-size="sm/md/lg", role="dialog", aria-modal="true", aria-labelledby="제목id", aria-hidden="true" 모달 패널
dialog-header — 제목·설명 영역
dialog-title <h2> + id dialog-content의 aria-labelledby와 id 연결
dialog-description <p> + id dialog-content의 aria-describedby와 연결 (선택)
dialog-footer data-align="start" (선택) 하단 버튼 영역
dialog-close type="button", data-close-kind="icon", aria-label="Close" 우측 상단 X 닫기 버튼. 내부에 lucide "x" 아이콘 + <span data-slot="sr-only">Close</span>
인라인 닫기 버튼 data-dialog-close footer 안 버튼에 이 속성 추가 시 다이얼로그 닫힘

Select & Combobox

Select와 Combobox 모두 data-slot="combobox" 컴포넌트를 사용합니다. Select는 data-mode="select"로 검색 없이 선택만, Combobox는 기본값으로 검색 포함입니다.

data-slot 속성 설명
combobox data-mode="select" (Select 시) 루트 래퍼
input-group — input + 버튼을 가로로 묶는 래퍼
combobox-input type="text", readonly(Select 시), autocomplete="off", aria-label 선택된 값 표시 입력창
input-group-button type="button", data-combobox-trigger, aria-expanded="false" 드롭다운 열기 버튼 (chevron-down 아이콘)
combobox-content data-state="closed" 드롭다운 패널. JS가 열림/닫힘 관리
combobox-list role="listbox" 옵션 목록
combobox-item data-value="값", role="option" 각 선택 옵션 (<div>)

Checkbox

네이티브 input[type=checkbox] 대신 <button role="checkbox">를 사용합니다. 체크 상태는 JS가 aria-checked와 data-checked로 관리합니다.

패턴 마크업
기본 <button type="button" role="checkbox" data-slot="checkbox" id="cb-1" aria-checked="false" aria-label="레이블"><span data-slot="checkbox-indicator" aria-hidden="true"><i data-lucide="check"></i></span></button>
체크된 초기값 aria-checked="true" + data-checked="true" 추가
라벨 연결 <label data-slot="label" for="cb-1">텍스트</label>
field 가로 배치 <div data-slot="field" role="group" data-orientation="horizontal"> 안에 checkbox + label 배치
비활성 disabled 속성 + 부모 field에 data-disabled="true"

Switch

토글 스위치. data-state="unchecked"가 기본값입니다.

패턴 마크업
기본 <button type="button" role="switch" data-slot="switch" id="sw-1" aria-checked="false" data-state="unchecked" aria-label="기능명"><span data-slot="switch-thumb"></span></button>
라벨 연결 (왼쪽 라벨) <div data-slot="field" data-orientation="horizontal"><label data-slot="label" for="sw-1">기능명</label>[switch]</div>
설명 포함 field 안에 <div data-slot="field-content"><label data-slot="field-label" for="sw-1">...</label><p data-slot="field-description">...</p></div> + switch 배치
켜진 초기값 aria-checked="true" + data-state="checked"

아이콘

Lucide 아이콘 라이브러리를 사용합니다. <i data-lucide="아이콘명"></i> 태그를 쓰면 JS가 SVG로 교체합니다. 페이지 로드 후 반드시 lucide.createIcons()를 호출하세요.

규칙 사용법
기본 선언 <i data-lucide="아이콘명" aria-hidden="true"></i>
아이콘명 형식 kebab-case 소문자. 예: arrow-right, chevron-down, x, check, circle-alert
장식 아이콘 aria-hidden="true" 필수
아이콘 전용 버튼 버튼에 aria-label="동작 이름"으로 의미 제공
뱃지 내 아이콘 위치 data-icon="inline-start"(왼쪽) / data-icon="inline-end"(오른쪽)
초기화 document.addEventListener('DOMContentLoaded', () => lucide.createIcons())

CSS 변수 커스터마이징

모든 색상·간격·타이포그래피는 CSS 변수로 정의됩니다. :root에서 원하는 값을 재정의해 테마를 변경합니다. 하드코딩된 값(#fff, 16px)은 절대 쓰지 마세요.

색상 토큰

시맨틱 토큰을 사용합니다. 팔레트 변수(--color-blue-500)를 직접 참조하면 다크모드에서 자동 전환되지 않습니다.

변수 용도
--color-background 페이지 배경
--color-foreground 기본 텍스트
--color-card / --color-card-foreground 카드 배경 / 카드 텍스트
--color-primary / --color-primary-foreground 주요 액션 색상 / 그 위 텍스트
--color-secondary / --color-secondary-foreground 보조 색상 / 그 위 텍스트
--color-muted / --color-muted-foreground 비활성 배경 / 보조 텍스트
--color-accent / --color-accent-foreground hover 강조 / 그 위 텍스트
--color-destructive / --color-destructive-foreground 삭제·오류 색상 / 그 위 텍스트
--color-border 기본 테두리
--color-input 입력 필드 테두리
--color-ring 포커스 아웃라인

간격 (Spacing)

기본 단위 --spacing = 0.25rem (4px). calc(var(--spacing) * N) 형태로만 사용합니다.

표현식 값 주요 용도
calc(var(--spacing) * 1) 4px 미세 간격
calc(var(--spacing) * 2) 8px 패딩 sm, 인라인 gap
calc(var(--spacing) * 3) 12px 패딩 기본, 컴팩트 간격
calc(var(--spacing) * 4) 16px 그리드 gap, 패딩 default
calc(var(--spacing) * 6) 24px 섹션 내부 gap
calc(var(--spacing) * 8) 32px 컴포넌트 높이 (버튼, 메뉴)

타이포그래피

카테고리 변수 값
폰트 --font-sans Pretendard (본문)
폰트 --font-mono 코드·데이터
크기 --text-xs ~ --text-5xl 12px ~ 48px
굵기 --font-weight-normal/medium/semibold/bold 400 / 500 / 600 / 700
행간 --leading-normal 1.5
자간 --tracking-base -0.01em (Pretendard 한글 권장)

테두리 반지름

변수 용도
--radius-sm 배지, 태그, 소형 요소
--radius-md 버튼, 인풋, 셀렉트
--radius-lg 카드, 드롭다운, 팝오버
--radius-xl 모달, 시트, 대형 패널

다크모드

<html> 요소에 .dark 클래스를 토글하는 방식으로 동작합니다. 별도의 CSS 작업 없이 모든 시맨틱 색상 토큰이 자동으로 다크모드 값으로 전환됩니다.

방법 코드
다크모드 적용 document.documentElement.classList.add('dark')
라이트모드 복귀 document.documentElement.classList.remove('dark')
토글 document.documentElement.classList.toggle('dark')
시스템 기본값 따르기 window.matchMedia('(prefers-color-scheme: dark)').matches로 판단 후 적용
초기 로드 시 깜빡임 방지 <head> 안 인라인 스크립트로 클래스 즉시 적용 (CSS 로드 전에 실행)

금지 사항

아래 패턴은 이 디자인 시스템과 충돌하거나 일관성을 깨뜨립니다.

금지 대신
컴포넌트에 임의 클래스 추가 (<button class="btn-primary">) data-slot="button" data-variant="default" 사용
인라인 스타일로 색상·간격 지정 (style="color:#fff") CSS 파일에 [data-slot] 선택자로 추가
팔레트 변수 직접 참조 (var(--color-blue-500)) 시맨틱 토큰 (var(--color-primary)) 사용
하드코딩 값 (16px, #1a1a1a, 0.875rem) calc(var(--spacing) * 4), var(--color-foreground)
<div onclick>로 버튼 대체 <button type="button"> 사용
아이콘 전용 버튼에 aria-label 생략 aria-label="동작이름" 필수
<label> 없는 <input> for/id 연결 또는 aria-label
