Alert

중요한 정보나 상태를 사용자에게 알리는 콜아웃 컴포넌트입니다.

잠깐만요!

CLI를 통해 컴포넌트와 의존성을 추가하거나 직접 파일을 복사해 사용할 수 있습니다.

Default

기본 variant. 일반 안내·정보를 전달할 때 사용합니다.

잠깐만요!

CLI를 통해 컴포넌트와 의존성을 추가하거나 직접 파일을 복사해 사용할 수 있습니다.

Destructive

data-variant="destructive"로 오류·위험 상황을 강조합니다.

오류

세션이 만료되었습니다. 다시 로그인해 주세요.

Info

data-color="info"로 정보성 알림을 표시합니다.

안내

새로운 버전이 출시되었습니다. 지금 업데이트하면 최신 기능을 사용할 수 있습니다.

Success

data-color="success"로 성공 상태를 알립니다.

결제 완료

결제가 정상적으로 처리되었습니다. 주문 내역은 이메일로 전송됩니다.

Warning

data-color="warning"로 주의가 필요한 상황을 강조합니다.

구독 만료 예정

구독이 3일 후 만료됩니다. 서비스 중단을 방지하려면 지금 갱신하세요.

Error

data-color="error"로 오류 상태를 표시합니다.

업로드 실패

파일 크기가 허용 용량(10MB)을 초과했습니다. 파일을 압축한 후 다시 시도해 주세요.

API Reference

Alert

알림 루트 요소입니다. role="alert"이 자동으로 적용됩니다.

속성 타입 기본값 설명
data-variant "default" | "destructive" "default" 알림의 시각적 스타일을 지정합니다.
data-color "info" | "success" | "warning" | "error" — 시스템 색상을 적용합니다. subtle 배경·테두리·텍스트가 함께 지정됩니다.

AlertTitle

슬롯 태그 설명
data-slot="alert-title" div 알림의 제목을 표시합니다. 1줄로 잘립니다.

AlertDescription

슬롯 태그 설명
data-slot="alert-description" div 알림의 본문 설명을 표시합니다. 내부 p 태그에 자동으로 여유 행간이 적용됩니다.
