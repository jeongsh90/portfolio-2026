API Reference

Command

data-slot="command" 루트에 아래 속성을 사용합니다.

속성 타입 설명
data-bordered="true" boolean 테두리 표시 (인라인 팔레트용)

CommandItem

속성 설명
data-disabled="true" 항목 비활성화 (선택·키보드 탐색 제외)
data-selected="true" 키보드/마우스로 강조된 항목 (JS가 설정)

Dialog (Command Dialog)

속성 설명
data-command="true" dialog-content에 적용 — 패딩 제거, 닫기 버튼 숨김
