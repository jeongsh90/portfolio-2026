Toolbar

data-slot="editor-toolbar"에 포맷 버튼 그룹을 배치합니다. data-editor-command으로 document.execCommand 또는 커스텀 동작(코드 블록, 링크, 전체 화면)을 연결합니다.

명령 설명
bold, italic, underline, strikeThrough텍스트 스타일
insertUnorderedList, insertOrderedList목록
justifyLeft … justifyFull정렬
codeBlock언어 선택이 있는 코드 블록 삽입
createLink, unlink, insertImage링크·이미지
fullscreen에디터 전체 화면 토글

API Reference

Editor

data-slot="editor" 루트입니다. initEditors()(js/extra/editor.js)가 툴바·코드 블록 하이라이트를 처리합니다.

속성 / 슬롯 설명
editor-toolbar포맷 버튼·Heading 선택
editor-contentcontenteditable 편집 영역
editor-code-block다크 테마 코드 블록 + 언어 선택
data-full-item"true"일 때 그리드 최대 너비 제한 해제
data-editor-fullscreen"true"일 때 전체 화면 오버레이
