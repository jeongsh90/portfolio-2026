API Reference

Carousel

data-slot="carousel" 루트 컨테이너입니다. 슬라이드 동작은 Swiper JS가 담당하고, 스타일은 shadcn Carousel CSS를 사용합니다.

속성 타입 기본값 설명
data-orientation "horizontal" | "vertical" "horizontal" 스크롤 방향.
data-align "start" | "center" "start" 슬라이드 정렬.
data-spacing "1" | "4" "4" 슬라이드 간격(spacing 단위).
data-basis "full" | "half" | "third" | "half-third" "full" Swiper slidesPerView 매핑. half-third는 lg에서 3열.
data-loop "true" | "false" "false" 무한 루프.
data-start-index number 0 초기 슬라이드 인덱스.
data-autoplay "true" | "false" "false" 자동 재생.
data-autoplay-delay number 2000 자동 재생 간격(ms).
data-carousel-api "true" | "false" "false" 슬라이드 상태 표시 연동.

CarouselContent

data-slot="carousel-content" Swiper 뷰포트(class="swiper")입니다.

속성 타입 기본값 설명
추가 속성 없음

CarouselItem

data-slot="carousel-item" 개별 슬라이드(class="swiper-slide")입니다.

속성 타입 기본값 설명
data-basis "full" | "half" | "third" | "half-third" "full" 슬라이드 너비(또는 세로 높이) 비율.

CarouselPrevious

data-slot="carousel-previous" 이전 슬라이드 버튼입니다.

속성 타입 기본값 설명
시작 슬라이드에서 disabled.

CarouselNext

data-slot="carousel-next" 다음 슬라이드 버튼입니다.

속성 타입 기본값 설명
마지막 슬라이드에서 disabled.
