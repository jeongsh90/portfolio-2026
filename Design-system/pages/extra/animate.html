Animate

CSS @keyframes 기반 애니메이션 유틸리티입니다. data-animate 속성으로 요소에 애니메이션을 적용하고, 클릭하면 다시 재생됩니다.

Fade

투명도를 이용한 등장 애니메이션입니다. 방향 없이 fade-in, 또는 상·하·좌·우 방향에서 등장합니다.

Slide

요소가 외부에서 슬라이드해 들어오는 애니메이션입니다. 스테이지 영역을 벗어나 시작하므로 컨테이너가 overflow: hidden으로 클립됩니다.

Zoom

크기를 확대·축소하며 등장하는 애니메이션입니다. zoom-in은 작게 시작, zoom-out은 크게 시작합니다.

Bounce

탄성 있게 튀어 들어오는 애니메이션입니다. 생동감 있는 강조 등장에 사용합니다.

Rotate

회전하며 등장하는 애니메이션입니다. -200deg에서 시작해 0deg로 정착합니다.

Flip

3D 원근법을 이용해 X축 또는 Y축을 중심으로 뒤집히며 등장합니다.

API Reference

data-animate

요소에 data-animate 속성을 추가하면 해당 키프레임 애니메이션이 즉시 적용됩니다. 클릭 리플레이는 initAnimateDemos()가 처리합니다.

값 분류 설명
fade-inFade투명도 0 → 1
fade-in-upFade아래에서 위로 페이드인
fade-in-downFade위에서 아래로 페이드인
fade-in-leftFade왼쪽에서 오른쪽으로 페이드인
fade-in-rightFade오른쪽에서 왼쪽으로 페이드인
slide-in-upSlide아래 200%에서 슬라이드인
slide-in-downSlide위 200%에서 슬라이드인
slide-in-leftSlide왼쪽 200%에서 슬라이드인
slide-in-rightSlide오른쪽 200%에서 슬라이드인
zoom-inZoomscale 0.6 → 1 (페이드 포함)
zoom-outZoomscale 1.4 → 1 (페이드 포함)
zoom-in-upZoom줌인 + 위로 이동
zoom-in-downZoom줌인 + 아래로 이동
zoom-in-leftZoom줌인 + 왼쪽에서 이동
zoom-in-rightZoom줌인 + 오른쪽에서 이동
bounce-inBounce탄성 있게 줌인 등장
bounce-in-upBounce아래에서 탄성 있게 등장
bounce-in-downBounce위에서 탄성 있게 등장
bounce-in-leftBounce왼쪽에서 탄성 있게 등장
bounce-in-rightBounce오른쪽에서 탄성 있게 등장
rotate-inRotate-200deg 회전하며 등장
flip-in-xFlipX축 3D 플립 등장
flip-in-yFlipY축 3D 플립 등장

CSS Variables

변수 기본값 설명
--animate-duration0.64s애니메이션 재생 시간
--animate-distancecalc(var(--spacing) * 6)Fade/Zoom 이동 거리
--animate-distance-slide200%Slide 이동 거리
--animate-easecubic-bezier(0.43,0.13,0.23,0.96)기본 이징
--animate-ease-bouncecubic-bezier(0.215,0.61,0.355,1)Bounce 이징
