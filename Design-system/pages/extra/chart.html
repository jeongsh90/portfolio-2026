Bar Chart

data-chart-type="bar"로 그룹형 막대 차트를 렌더링합니다. CartesianGrid·XAxis 스타일의 그리드와 축 레이블을 포함합니다.

Line Chart

추세를 표시하는 라인 차트입니다. Recharts LineChart와 동일하게 여러 시리즈를 겹쳐 그립니다.

Area Chart

data-chart-type="area"로 선 아래 영역을 채웁니다. data-chart-curve="true"는 Recharts type="monotone"처럼 곡선을, data-chart-gradient="true"는 상단에서 하단으로 페이드되는 그라데이션 fill을 적용합니다.

Linear

Gradient + Curve

Pie Chart

범주별 비율을 표시하는 파이 차트입니다. data-chart-x는 라벨 키, data-chart-value는 값 키입니다.

Donut Chart

가운데가 비어 있는 도넛 차트입니다. Recharts PieChart + innerRadius 패턴이며, data-chart-inner-radius로 구멍 크기(0~1)를 조절합니다. 중앙에는 합계가 표시됩니다.

Tooltip

차트 위에 마우스를 올리면 ChartTooltipContent 스타일의 툴팁이 표시됩니다. data-chart-tooltip="false"로 비활성화할 수 있습니다.

Theming

ChartConfig의 color는 --color-{key} CSS 변수로 주입됩니다. 기본 팔레트는 --chart-1 ~ --chart-5 토큰을 사용합니다.

API Reference

Chart

data-slot="chart" 루트에 아래 속성을 지정합니다. 렌더링은 initCharts() (js/extra/chart.js)가 담당합니다.

속성 타입 기본값 설명
data-chart-type "bar" | "line" | "area" | "pie" | "donut" "bar" 차트 종류
data-chart-dataset "monthly" | "daily" | "pie" "monthly" 내장 샘플 데이터셋 키
data-chart-data JSON array — 커스텀 데이터 (dataset보다 우선)
data-chart-config JSON object — 시리즈별 label, color (ChartConfig)
data-chart-x string "month" X축·라벨 데이터 키
data-chart-series string "desktop,mobile" 쉼표 구분 시리즈 키
data-chart-value string "visitors" 파이 차트 값 키
data-chart-height number 250 차트 높이(px)
data-chart-grid boolean true CartesianGrid 표시
data-chart-tooltip boolean true 호버 툴팁
data-chart-legend boolean true 범례 표시
data-chart-curve boolean false Area·Line 곡선 보간 (monotone)
data-chart-gradient boolean false Area 그라데이션 fill
data-chart-inner-radius number 0.58 도넛 내부 반경 비율 (외径 대비)
data-chart-center-label string "Total" 도넛 중앙 라벨
data-chart-slice-gap number 0.02 (donut) 슬라이스 간 각도 간격(라디안)
data-chart-active-series string — 단일 시리즈만 표시 (인터랙티브 바)

Slots

슬롯 설명
chart-container SVG가 렌더링되는 반응형 래퍼 (min-height 필수)
chart-tooltip ChartTooltipContent 스타일 툴팁
chart-legend 시리즈 범례
