Date Picker

Popover와 Calendar를 조합해 날짜를 선택하는 컴포넌트입니다. 별도의 Date Picker 루트 컴포넌트 없이 두 컴포넌트를 함께 사용합니다.

Basic

라벨과 함께 사용하는 기본 날짜 선택 필드입니다.

Range Picker

날짜 범위를 선택합니다. data-mode="range", data-months="2"를 함께 사용합니다.

Date of Birth

생년월일 선택에 적합한 드롭다운 캡션 레이아웃입니다. 날짜 선택 시 팝오버가 닫힙니다.

Input

입력 필드와 캘린더 버튼을 함께 사용합니다. ↓ 키로 캘린더를 열 수 있습니다.

Time Picker

날짜 선택과 시간 입력을 함께 사용합니다.

Composition

Date Picker는 아래 슬롯을 조합해 구성합니다.

Popover
├── PopoverTrigger
└── PopoverContent (data-fit="true")
    └── Calendar

API Reference

Date Picker

data-slot="date-picker" 래퍼에 아래 속성을 사용합니다.

속성 타입 기본값
data-mode "single" | "range" "single"
data-format "long" | "medium" | "input" | "locale" "long"
data-close-on-select boolean true (range는 false 권장)

PopoverContent

속성 설명
data-fit="true" 캘린더에 맞게 width: auto, padding: 0 적용
data-align "start" | "end" — 트리거 기준 정렬
data-side-offset 트리거와의 수직 간격 (px, 기본 4)
data-align-offset 수평 오프셋 (px)
