Slider

범위 내에서 값을 선택하는 슬라이더 컴포넌트입니다.

Range

두 값을 지정하는 범위 슬라이더입니다.

Multiple Thumbs

여러 thumb로 복수 값을 선택합니다.

Vertical

data-orientation="vertical"로 세로 슬라이더를 만듭니다.

Controlled

값 변경 시 라벨 옆에 현재 값을 표시합니다.

0.3, 0.7

Disabled

data-disabled="true"로 슬라이더를 비활성화합니다.

API Reference

Slider

Radix Slider 기반 루트 컨테이너입니다.

속성 타입 기본값 설명
data-min number 0 최솟값.
data-max number 100 최댓값.
data-step number 1 증감 단위.
data-default-value string — 초기 값. 복수 thumb는 |로 구분.
data-value string — 현재 값. JS가 동기화합니다.
data-orientation "horizontal" | "vertical" "horizontal" 슬라이더 방향.
data-disabled "true" | "false" "false" 비활성화 여부.

SliderTrack

data-slot="slider-track" 슬라이더 트랙 배경입니다. Track 안에 Range를 중첩합니다.

속성 타입 기본값 설명
추가 속성 없음

SliderRange

data-slot="slider-range" 선택된 구간을 표시하는 채워진 영역입니다. 위치·크기는 JS가 thumb 값에 맞춰 동기화합니다.

속성 타입 기본값 설명
추가 속성 없음

SliderThumb

data-slot="slider-thumb" 드래그 가능한 thumb입니다. role="slider"와 ARIA 값 속성을 사용합니다.

속성 타입 기본값 설명
role "slider" "slider" 접근성 역할. 필수.
tabindex 0 | -1 0 비활성화 시 -1.
aria-valuemin number — Slider data-min과 동기화.
aria-valuemax number — Slider data-max와 동기화.
aria-valuenow number — 현재 thumb 값. JS가 갱신.
aria-orientation "horizontal" | "vertical" "horizontal" Slider data-orientation과 동기화.
aria-labelledby string — 연결된 라벨 id. Controlled 예시 참고.

SliderValue

data-slot="slider-value" Controlled 예시에서 현재 값을 표시하는 출력 요소입니다.

속성 타입 기본값 설명
data-slider-output string — 연결할 Slider의 id 값.
