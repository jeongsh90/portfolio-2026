API Reference

Item

data-slot="item" 루트 컨테이너입니다.

속성 타입 기본값 설명
data-variant "default" | "outline" | "muted" "default" 배경·테두리 스타일.
data-size "default" | "sm" | "xs" "default" 패딩·간격.

ItemGroup

data-slot="item-group" 관련 item 목록 컨테이너입니다.

속성 타입 기본값 설명
role "list" "list" 목록 접근성 역할.
data-gap "4" — 항목 간격(Image 예시).
data-layout "grid" — 3열 그리드(Header 예시).

ItemSeparator

data-slot="item-separator" 그룹 내 구분선입니다.

속성 타입 기본값 설명
role "separator" — 구분선 접근성 역할.

ItemMedia

data-slot="item-media" 아이콘·이미지·아바타 미디어 영역입니다.

속성 타입 기본값 설명
data-variant "default" | "icon" | "image" "default" 미디어 레이아웃.

ItemContent

data-slot="item-content" 제목·설명을 감싸는 flex 영역입니다.

속성 타입 기본값 설명
data-gap "1" — 내부 간격(Group 예시).
data-align "center" — 텍스트 정렬(Image duration).

ItemTitle

data-slot="item-title" item 제목입니다.

속성 타입 기본값 설명
data-clamp "1" — 한 줄 말줄임(Image 예시).

ItemDescription

data-slot="item-description" item 설명(p)입니다.

속성 타입 기본값 설명
추가 속성 없음

ItemActions

data-slot="item-actions" 버튼·아이콘 등 액션 영역입니다.

속성 타입 기본값 설명
추가 속성 없음

ItemHeader

data-slot="item-header" 콘텐츠 위 전체 너비 헤더입니다.

속성 타입 기본값 설명
추가 속성 없음

ItemFooter

data-slot="item-footer" 콘텐츠 아래 전체 너비 푸터입니다.

속성 타입 기본값 설명
추가 속성 없음
