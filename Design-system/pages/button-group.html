Button Group

관련 버튼을 일관된 스타일로 묶는 컨테이너입니다. 액션 그룹, 스플릿 버튼 등에 사용합니다.

Orientation

data-orientation 속성으로 버튼 그룹의 배치 방향을 변경합니다.

Size

각 버튼의 data-size 속성으로 그룹 크기를 조절합니다.

Nested

ButtonGroup을 중첩해 간격이 있는 복합 레이아웃을 만듭니다.

Separator

ButtonGroupSeparator로 그룹 내 버튼을 시각적으로 구분합니다. outline variant는 테두리가 있어 구분선이 필요 없습니다.

Split

ButtonGroupSeparator로 두 버튼을 나눠 스플릿 버튼 그룹을 만듭니다.

Input

입력 필드와 버튼을 함께 묶습니다.

Input Group

InputGroup을 ButtonGroup으로 감싸 복합 입력 레이아웃을 만듭니다.

API Reference

ButtonGroup

관련 버튼을 일관된 스타일로 묶는 컨테이너입니다.

속성 타입 기본값
data-orientation "horizontal" | "vertical" "horizontal"

ButtonGroupSeparator

버튼 그룹 내 버튼을 시각적으로 구분합니다.

속성 타입 기본값
data-orientation "horizontal" | "vertical" "vertical"

ButtonGroupText

버튼 그룹 내 텍스트를 표시합니다.

속성 타입 기본값
asChild boolean false
