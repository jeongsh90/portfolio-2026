Sonner

화면 가장자리에 짧은 알림 메시지를 띄우는 토스트 컴포넌트입니다. 위치·유형·설명을 조합해 다양한 알림을 표현할 수 있습니다.

Types

data-sonner-type으로 토스트 유형을 지정합니다. 유형에 따라 아이콘 색상이 달라집니다.

Description

data-sonner-description으로 제목 아래 부가 설명을 추가합니다.

Position

data-sonner-position으로 토스트가 나타날 위치를 지정합니다.

Toast

API Reference

Toaster

토스트를 렌더링하는 루트 컨테이너입니다. 레이아웃에 한 번만 배치합니다.

속성 타입 기본값 설명
data-position "top-left" | "top-center" | "top-right" | "bottom-left" | "bottom-center" | "bottom-right" "bottom-right" 토스트가 나타날 화면 위치

Toast trigger

data-sonner-trigger를 가진 버튼에 추가하는 속성입니다.

속성 타입 기본값 설명
data-sonner-trigger boolean — 토스트 트리거 요소로 지정
data-sonner-message string — 토스트 제목 텍스트
data-sonner-description string — 제목 아래 부가 설명 텍스트
data-sonner-type "success" | "info" | "warning" | "error" | "promise" — 토스트 유형 — 아이콘 색상에 반영됨
data-sonner-position "top-left" | "top-center" | "top-right" | "bottom-left" | "bottom-center" | "bottom-right" Toaster 기본값 해당 토스트의 위치만 개별 지정
data-sonner-action-label string — 토스트 내 액션 버튼 레이블

Toast

렌더링되는 토스트 카드 요소입니다.

속성 타입 기본값 설명
data-type "success" | "info" | "warning" | "error" | "loading" — 유형별 아이콘 색상 적용
data-variant "soft" — 시스템 색상의 은은한 배경 + 테두리 (data-type 필요)
data-state "closed" — 닫힘 애니메이션 트리거
data-static boolean — 애니메이션 없이 정적으로 표시 (미리보기용)
