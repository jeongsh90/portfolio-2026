API Reference

Skeleton

data-slot="skeleton" 로딩 placeholder 블록입니다. 크기·모양은 className 또는 레이아웃 래퍼로 지정합니다.

속성 타입 기본값 설명
className string — 너비·높이·모서리 등 추가 스타일.
