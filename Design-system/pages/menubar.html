Menubar

데스크톱 앱 스타일의 가로 메뉴 바입니다. 클릭으로 메뉴를 열고 서브메뉴, 체크박스, 라디오, 단축키를 지원합니다.

API Reference

MenubarContent

data-slot="menubar-content" 드롭다운 패널입니다. data-state로 열림 상태를 제어합니다.

속성 타입 기본값
data-state "open" | "closed" "closed"
data-size "sm" —

MenubarItem

data-slot="menubar-item" 일반 메뉴 항목입니다.

속성 타입 기본값
data-inset "true" —
disabled boolean false

MenubarCheckboxItem

data-slot="menubar-checkbox-item" 토글 가능한 체크 항목입니다.

속성 타입 기본값
aria-checked "true" | "false" "false"

MenubarRadioItem

menubar-radio-group 안에서 단일 선택 항목을 표시합니다.

속성 타입 기본값
aria-checked "true" | "false" "false"
data-value string —
