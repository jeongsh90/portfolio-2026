Aspect Ratio

콘텐츠를 원하는 가로·세로 비율로 표시하는 컴포넌트입니다. --aspect-ratio CSS 변수로 비율을 지정합니다.

Square

--aspect-ratio: 1 / 1로 정사각형 비율을 사용합니다. 정사각형 이미지 표시에 유용합니다.

Portrait

--aspect-ratio: 9 / 16로 세로형 비율을 사용합니다. 세로 방향 이미지 표시에 유용합니다.

API Reference

AspectRatio

콘텐츠를 지정한 가로·세로 비율로 표시합니다.

속성 타입 기본값 설명
ratio number — 가로 ÷ 세로 비율 (예: 16 / 9). HTML에서는 style="--aspect-ratio: 16 / 9"로 지정
className string — 추가 스타일 클래스
