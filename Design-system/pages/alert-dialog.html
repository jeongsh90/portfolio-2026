Alert Dialog

사용자의 명시적인 확인이 필요한 중요한 작업에 사용하는 모달 다이얼로그입니다. 오버레이 클릭이나 Esc 키로 닫히지 않아 의도치 않은 파괴적 액션을 방지합니다.

정말 계속하시겠습니까?

이 작업은 되돌릴 수 없습니다. 계정이 영구적으로 삭제되며 서버에서 모든 데이터가 제거됩니다.

Basic

제목, 설명, 취소·확인 버튼으로 구성된 기본 Alert Dialog입니다.

정말 계속하시겠습니까?

이 작업은 되돌릴 수 없습니다. 계정이 영구적으로 삭제되며 서버에서 모든 데이터가 제거됩니다.

Small

data-size="sm"으로 너비를 줄인 소형 다이얼로그입니다. 푸터 버튼이 자동으로 2열 그리드로 배치됩니다.

정말 계속하시겠습니까?

이 작업은 되돌릴 수 없습니다. 계정이 영구적으로 삭제되며 서버에서 모든 데이터가 제거됩니다.

Media

data-slot="alert-dialog-media"로 헤더에 아이콘·이미지를 추가합니다. 대형 화면에서 미디어가 제목·설명 옆에 나란히 배치됩니다.

프로젝트를 공유하시겠습니까?

팀원들이 이 프로젝트를 열람하고 편집할 수 있게 됩니다. 언제든지 공유 설정을 변경할 수 있습니다.

Small with Media

data-size="sm"과 미디어를 함께 사용한 예시입니다.

Bluetooth 활성화

주변 기기와 연결하려면 Bluetooth를 켜야 합니다.

Destructive

삭제 등 되돌릴 수 없는 작업에 사용합니다. 확인 버튼을 data-variant="destructive"로 강조합니다.

채팅을 삭제하시겠습니까?

이 채팅 기록은 영구적으로 삭제되며 복구할 수 없습니다.

API Reference

AlertDialog

Alert Dialog 루트 컨테이너입니다.

슬롯 설명
data-slot="alert-dialog" 루트 컨테이너. 트리거·오버레이·콘텐츠를 감쌉니다.

AlertDialogContent

속성 타입 기본값 설명
data-size "default" | "sm" "default" 다이얼로그 최대 너비. sm은 320px, default는 512px(sm 브레이크포인트 이상).
role "alertdialog" "alertdialog" 스크린 리더에 경고 다이얼로그임을 알립니다.
aria-modal "true" "true" 모달 영역 외부 콘텐츠를 보조 기술에서 숨깁니다.
aria-labelledby string — alert-dialog-title 요소의 id와 연결합니다.
aria-describedby string — alert-dialog-description 요소의 id와 연결합니다.

AlertDialogAction / AlertDialogCancel

속성 타입 기본값 설명
data-slot="alert-dialog-action" — — 확인 버튼. 클릭 시 다이얼로그가 닫힙니다.
data-slot="alert-dialog-cancel" — — 취소 버튼(data-variant="outline" 기본). 클릭 시 다이얼로그가 닫힙니다.
data-variant "default" | "outline" | "ghost" | "destructive" | "secondary" | "link" action: "default" / cancel: "outline" 버튼 스타일을 지정합니다.
